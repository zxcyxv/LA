> ## ⚠ §12~§15 에서 이 문서의 결론 둘이 뒤집혔다
>
> 같은 날 SNR 로 다시 재면서 §9-1 의 구멍을 닫았고, 그 과정에서 **§5(창 넓히기)와

> |---|---|---|

> | 처방 `logtau + γ·τ^{−1}` | β 를 1.5 로 복원 | **방향이 반대다.** 장기기억엔 β 가 **낮아야** 좋다 |

> 지수 망각이 **거듭제곱 망각**으로 바뀐다고 주장했고, 같은 문서 §10 이 스스로 이렇게
> 적어두었다:
>
> > §5.2 의 거듭제곱 망각 주장은 Fusi et al. 의 결과를 **유추 적용**한 것이다.
> > 우리 구조에서 실제로 거듭제곱이 나오는지는 **계산도 측정도 하지 않았다.**
>

>

## 1. 배경 — 무엇이 걸려 있었나

`MISALIGNMENT.md §5` 의 사슬:

```
막전위 동형 → 문턱 → 이산 발화 → 공고화 촉발 → 느린 저장소 이전 → 장기기억
```

갈래 C 가 앞의 두 링크를 통과시켰고(§9.3), 링크 3 을 구현했다(§9.9). **링크 4 가
미구현이고, 거기가 장기기억이 실제로 나오는 자리로 지목돼 있었다.**

그 설계가 §6.4 다.

```
S_t[j] = λ_j S_{t-1}[j] + γ_j k_{t,j} v_t†                  (기존 — 빠른 흔적)
W_t[j] = μ_j W_{t-1}[j] + η_j · g_t · S_t[j]                (추가 — 느린 저장, |μ_j| > |λ_j|)
f_t    = p^{-1/2} · Re[ q_t†( S_t + c·W_t ) ]
```

주장은 셋이었다.

1. 전이가 채널별 **하삼각 2×2** 라 대각성·병렬 스캔이 보존된다
2. 닫힌 형태가 `(λ^{Δ+1} − μ^{Δ+1})/(λ − μ)` — `[D]` 의 alpha function. **`#5`(상승상)와
   `#6`(승격)이 같은 항이다**
3. 지수 망각 → **거듭제곱 망각** (Fusi, Drew & Abbott 2005)

**1 과 2 는 맞다. 3 이 틀렸다.**

## 2. `[A]` `W` 는 감쇠의 종류를 바꿀 수 없다

채널 하나를 임펄스로 때리고(`t=n` 에 기억 하나를 씀) `Δ = t−n` 뒤에 읽는다.
`g_t ≡ g` 를 상수로 두면:

```
S 기여 :  γ λ^Δ
W 기여 :  η g γ · (μ^{Δ+1} − λ^{Δ+1}) / (μ − λ)
```

이 alpha function 을 **부분분수로 쪼개면**:

```
(μ^{Δ+1} − λ^{Δ+1})/(μ − λ)  ≡  [ μ·μ^Δ − λ·λ^Δ ] / (μ − λ)
```

실측: `max|캐스케이드 − 지수2개의 가중합| = 2.547e-11`

> **캐스케이드는 지수 두 개의 특정 가중합이다. 항등식이다.**

그리고 `|μ| > |λ|` 이므로 `Δ→∞` 에서 `K(Δ) ~ μ^Δ` — **여전히 지수다.** 시정수만 길어진다.

이것은 우연이 아니라 정리다.

> 유한 차원 **선형 시불변계**의 임펄스 응답은 지수의 유한 합이다. 거듭제곱이 될 수 없다.

`S` 와 `W` 는 (게이트가 주어지면) 계수가 고정된 선형 재귀다. 항을 2개로 늘리든 10개로
늘리든 감쇠의 **종류**가 안 바뀐다.

### 2.1 그럼 `W` 는 무엇을 주나 — 꼬리가 아니라 머리

피크 lag 실측 (`p=128`, `τ_W = 8τ_S`):

| | 피크 lag |
|---|---:|
| `S` 만 | **1** |
| `S + W` 캐스케이드 | **31,623** |

`W` 가 바꾸는 것은 커널의 **머리 모양**이다 — lag 0 최대에서 상승상을 가진 창으로.

| `W` 가 고치는 것 | 판정 |
|---|---|
| 어긋남 **`#5`** — 상승상, 동시성 창, **앨리어싱 제거** (실극점 → 부호 반전 0회) | **유효** |
| 어긋남 `#4` — 공고화, **거듭제곱 망각** | **무효** |

§6.4 가 *"`#5`(상승상)와 `#6`(승격)이 같은 항이다"* 라고 쓴 것은 맞다. **그러나 그 항이
배달하는 것은 `#5` 뿐이다.** `EXTRAPOLATION.md §3.3` 이 필요로 한 앨리어싱 제거는 여전히
유효한 이유이므로 **`W` 를 버릴 필요는 없다. 다만 장기기억의 근거로는 못 쓴다.**

## 3. `[B]` 거듭제곱의 조건 — 밀도와 진폭

지수 혼합으로 거듭제곱을 근사하려면:

```
∫ A(τ) e^{−Δ/τ} ρ(τ) dτ = Γ(β)·Δ^{−β}      ⟺      A(τ)·ρ(τ) ∝ τ^{−1−β}
```

`A` 는 채널의 읽기 진폭, `ρ` 는 시정수 밀도다. 실측 (512채널, `τ ∈ [1,10⁶]` log 등간격
→ `ρ ∝ τ^{−1}`, 국소 로그-로그 기울기):

| 진폭 가중 | Δ=30 | Δ=1000 | Δ=30000 | 변동폭 |
|---|---:|---:|---:|---:|
| 균등 | −0.102 | −0.157 | −0.327 | 0.245 |
| `τ^{−0.25}` | −0.272 | −0.311 | −0.454 | 0.197 |
| `τ^{−0.5}` | −0.503 | −0.518 | −0.617 | 0.127 |
| **`τ^{−1.0}`** | **−1.000** | **−1.001** | **−1.030** | **0.065** |

**균등 진폭은 거듭제곱이 아니라 로그 감쇠다** — 기울기가 평평하지 않고 천천히 가팔라진다
(해석적으로 `ln(τ_max/Δ)`). `τ^{−β}` 가중이 기울기를 `−β` 에 고정한다.

## 4. `[C]` 레포는 이미 거듭제곱을 갖고 있다

`model0.py` 의 기본값이 `r_min=0.90, r_max=0.999`, 즉 **`|λ| 을 균등 추출**한다.
거기서 유도되는 시정수 밀도:

```
τ = −1/ln r   →   r = e^{−1/τ},   dr/dτ = e^{−1/τ}/τ²
r 균등  ⟹  ρ(τ) ∝ e^{−1/τ}/τ²  ∝  τ^{−2}          (τ ≫ 1)
```

그리고 실제 커널의 진폭 가중이 `γ_j = √(1−|λ_j|²)` 다 — `MISALIGNMENT.md §8.6` 의 식에서
`γ_j` 가 한 번 들어간다:

```
a_tn = p^{−1/2} Σ_j γ_j |z_tj||z_nj| e^{−α_jΔ} cos(arg z_nj − arg z_tj − ψ_j − ΔΦ_j)
                     ↑ 진폭 가중
γ(τ) = √(1 − e^{−2/τ}) ≈ √(2/τ) ∝ τ^{−1/2}
```

곱하면:

```
γ(τ)·ρ(τ) ∝ τ^{−1/2} · τ^{−2} = τ^{−5/2} = τ^{−1−β}    →    β = 3/2
```

실측:

| 초기화 | 진폭 | 예측 β | **실측 β** |
|---|---|---:|---|
| `decay_init='uniform'` | γ 없이 (이상화) | 1.0 | **0.990 ± 0.008** |
| **`decay_init='uniform'`** | **γ 포함 (실제 커널)** | **1.5** | **1.485 ± 0.019** |
| `decay_init='logtau'` | γ 없이 | 0.0 (로그) | 0.291 ± 0.137 |
| `decay_init='logtau'` | γ 포함 | 0.5 | 0.601 ± 0.097 |

**예측과 실측이 소수점 둘째 자리까지 맞는다.**

### 4.1 그래서 `MISALIGNMENT.md §5.2` 의 진단이 틀렸다

> **병렬 뱅크(현재) ≠ 캐스케이드(생물). 차이는 승격 경로 하나다.**

이 문장은 **병렬 뱅크가 지수 망각이라는 암묵적 전제** 위에 서 있다. 아니다.
**밀도만 맞으면 병렬 뱅크도 거듭제곱이다.** 그리고 레포의 기본값이 이미 맞아 있다.

Fusi 가 승격 경로를 필요로 한 이유는 그의 시냅스가 **이산·유계·확률적**이라 시정수 밀도를
자유롭게 고를 수 없기 때문이다. 캐스케이드는 그 제약 하에서 밀도를 만드는 **우회로**다.
연속 값 뱅크는 밀도를 직접 고를 수 있으므로 그 우회로가 필요 없다.

> **같은 결과에 도달하는 두 경로이고, 우리 쪽은 짧은 경로를 이미 쓰고 있었다.**

## 5. `[D]` 진짜 병목 — 창의 배율

거듭제곱 근사는 `τ_min ≪ Δ ≪ τ_max` 안에서만 성립한다. 밖에서는 각각 상수와 지수로 돌아간다.

| 설정 | τ_max | 창 | **배율** | 실측 β |
|---|---:|---|---:|---|
| **`p=64, r_max=0.999` (현재 기본값)** | 999 | Δ∈[49,199] | **4.1×** | 1.465 ± 0.026 |
| `p=64, r_max=0.9999` | 9,999 | Δ∈[49,1982] | 40.4× | 1.366 ± 0.190 |
| `p=256, r_max=0.99999` | 99,999 | Δ∈[49,19767] | 403× | 1.294 ± 0.399 |
| `p=512, r_max=0.999999` | 999,999 | Δ∈[49,31623] | 645× | 1.455 ± 0.294 |

**4배 구간의 거듭제곱은 거듭제곱이라고 부를 수 없다.**

그리고 이 규모가 `EXTRAPOLATION.md §0` 의 관측과 맞물린다 — *"어떤 개입을 해도 한계는
학습 길이의 약 2배에서 왔다."* 창이 4배인데 2배에서 깨지는 것은 정합적이다.
**단 인과관계는 아직 주장할 수 없다. 검증 가능한 가설이다** (§9-2).

`r_max` 와 `p` 는 초기화 상수다. 새 파라미터도, 새 상태도, 새 연산도 없다.
**개입 비용이 0 이다.**

### 5.1 그런데 창을 넓히면 β 가 흔들린다

위 표에서 `p` 를 늘려도 변동폭이 오히려 커진다 (0.026 → 0.399). 원인은 **표본이 몰리는
것**이다. `r` 을 균등 추출하면 `τ = −1/ln r` 이 `r→1` 에서 비선형 폭발하므로 표본이
**작은 τ 로 몰린다.** `p=256, r_max=0.99999` 에서 τ 중앙값이 **19.5**, `τ>128` 채널이
**20/256** 뿐이다.

이것이 `EXTRAPOLATION.md §1-2` 가 실측한 그 현상이다 — *"명목 범위가 6.6~693 토큰이어도
실제 중앙값은 11.5 로 몰린다."*

## 6. `[F]` 두 초기화가 상충한다 — 그리고 둘 다 갖는 처방

| | 밀도 지수 | 덮기 |
|---|---|---|
| `uniform` (기본) | **맞다** (β=1.5) | **성기다** (τ>128 이 20/256) |
| `logtau` (EXTRAPOLATION 도입) | **틀렸다** (β=0.6, 로그에 가까움) | **고르다** (184/256) |

`EXTRAPOLATION.md` 가 길이 외삽을 고치려고 `logtau` 를 도입했을 때 **망각 곡선의 종류가
같이 바뀐다는 것을 몰랐다.** 당시 판정은 *"반증(미미), 0.840 → 0.902"* 였는데, 재는 축이
하나 빠져 있었다.

### 처방 — 표본 분포와 진폭 가중은 다른 손잡이다

`logtau` 로 뽑으면 `ρ ∝ τ^{−1}` 이므로, 진폭에 `τ^{−1}` 을 더 얹으면 곱이 `τ^{−2.5}` 로
복원된다 (`γ` 가 이미 `τ^{−0.5}` 를 준다).

```
A(τ) = γ(τ) · τ^{−1}        →      A·ρ ∝ τ^{−0.5}·τ^{−1}·τ^{−1} = τ^{−2.5}   →   β = 1.5
```

실측 (`p=256`):

| 설정 | τ 중앙값 | τ>128 | **실측 β** |
|---|---:|---:|---|
| `uniform, γ` (현재) | 19.5 | 20/256 | 1.294 ± 0.399 |
| `logtau, γ` | 976.1 | 184/256 | 0.600 ± 0.096 |
| **`logtau, γ·τ^{−1}`  ← 처방** | **976.1** | **184/256** | **1.505 ± 0.025** |

**처방이 셋 중 가장 좁은 변동폭으로 β=1.5 를 준다.** 덮기와 거듭제곱은 상충하지 않는다 —
**덮기는 표본 분포가, 지수는 진폭 가중이 정한다.** 각각 다른 손잡이다.

## 7. `[E]` β 는 파라미터 0 개짜리 다이얼이다

진폭을 `γ·τ^{−a}` 로 재가중했을 때:

| 진폭 | 실측 β |
|---|---|
| `γ·τ^{+1.0}` | 0.525 ± 0.029 |
| `γ·τ^{+0.5}` | 0.988 ± 0.009 |
| **`γ·τ^{0}` (현재)** | **1.485 ± 0.019** |
| `γ·τ^{−0.5}` | 1.983 ± 0.033 |
| `γ·τ^{−1.0}` | 2.476 ± 0.054 |

정확히 `β ≈ 1.49 − a` 로 선형이다.

> **망각 지수가 설계 가능한 양이고, 지금 그 값은 선택된 것이 아니라 초기화의 부산물이다.**

그리고 `CAPACITY.md §4.2` 가 *"`τ` 는 학습되지 않는다 — 초기화가 0.68 bpb 를 결정한다"* 를
실측했으므로, **초기화 분포가 곧 최종 분포다.** 그 발견이 여기서는 좋은 소식이다 —
β 가 초기화로 통제 가능하고 학습이 그것을 망치지 않는다.

## 8. 설계 지적 — 승격이 기억 단위가 아니라 시각 단위다

§6.4 의 `g_t` 는 **(토큰, 채널)당 스칼라 하나**이고, 그 시각의 `S` **전체**를 통째로
`W` 로 넘긴다. Fusi 의 캐스케이드는 시냅스마다 **자기 이력**에 따라 독립적으로 승격한다.

| | 무엇이 승격을 정하나 |
|---|---|
| Fusi 캐스케이드 | 그 시냅스가 **반복 강화됐는가** |
| §6.4 의 `g_t` | 망이 **그 순간 흥분해 있었는가** |

> **"반복 강화된 기억이 살아남는다" 가 아니라 "망이 흥분해 있던 순간에 저장소에 있던
> 것이 살아남는다" 다.** 기억별 선택이 아니라 시각별 선택이고, Fusi 의 메커니즘과 다르다.

`MISALIGNMENT.md §5.2` 가 *"한 기억의 운명이 쓰기 시점에 확정되고 이후 개정되지 않는다"* 를
현재 구조의 결함으로 지목했는데, `g_t` 승격은 그 결함을 **부분적으로만** 고친다 — 운명이
쓰기 시점이 아니라 **저장소에 머무는 동안의 시각들**에서 정해질 뿐, 여전히 그 기억 자신의
성질로는 안 정해진다.

## 9. 한계 — 무엇을 재지 않았나

정직하게 넷이다. 첫째가 가장 크다.

1. **SNR 이 아니라 신호 포락선만 쟀다.** Fusi 의 거듭제곱은 *신호/간섭잡음* 곡선이다.
   다른 기억들의 간섭도 같이 자라므로 SNR 은 다를 수 있다. **이 문서의 모든 β 는 신호
   쪽 지수다.** `PLASTICITY.md §6.5` 가 `N=300, p=64` 에서 간섭을 실측했으므로 그 실험을
   lag 별로 펼치면 잴 수 있다.
2. **포락선이지 실제 커널이 아니다.** 실제 `a_tn` 에는 `|z_tj||z_nj|` 와 `cos(...)` 가
   붙고, `MISALIGNMENT.md [D]` 가 40토큰에 부호 반전 36회를 실측했다. 진동을 벗긴 크기만
   쟀다. (거듭제곱 *포락선* 위의 진동이므로 `#5` 처방과 독립이다.)
3. **`g_t` 를 상수로 뒀다.** 시변 게이트면 LTI 가 아니라 `[A]` 의 정리가 엄밀히는 안
   걸린다. `g ∈ [0,1]` 유계라 종류를 바꿀 것 같지 않지만 **유일한 탈출구이므로 열어둔다.**
4. **학습 전 초기화 분포다.** 단 `CAPACITY.md §4.2` 에 의해 `τ` 는 학습되지 않으므로
   초기화가 곧 최종이라고 봐도 무리가 없다. `γ` 는 `|λ|` 에 종속이라 같이 고정된다.

그리고 §5.1 의 변동폭 문제는 이 문서에서 진단만 했다. `p` 를 얼마나 늘려야 주어진 창에서
변동폭이 얼마 이하로 떨어지는지는 스윕하지 않았다.

## 12. 측정 방식 — 재제시 회상

길이 `T=1600` 의 무작위 토큰열에서 **마지막 토큰을 위치 `T−1−Δ` 의 것과 같게** 놓는다.
그러면 커널의 마지막 행에서

```
신호 = A[T−1, T−1−Δ]        내용이 맞는 항목
잡음 = rms A[T−1, m]         m ≠ 자기·신호 — 다른 기억들의 간섭
SNR(Δ) = |신호| / 잡음
```

**`SNR ≥ 1` 인 최대 `Δ` 를 유효 기억 수명이라 부른다.** 이것이 이 레포 최초의 장기기억
단일 지표다 — 지금까지 잰 것(selective copy 정확도, bpb, 길이 외삽)은 전부 간접 지표였다.

### 12.1 현재 기본값의 곡선

| Δ | 신호 | 잡음 | SNR |
|---:|---:|---:|---:|
| 1 | 0.06021 | 0.00386 | 15.873 |
| 12 | 0.02357 | 0.00400 | 5.989 |
| 50 | 0.00786 | 0.00398 | 1.969 |
| **80** | 0.00827 | 0.00407 | **2.060** |
| 128 | 0.00322 | 0.00401 | 0.811 |
| 500 | 0.00089 | 0.00412 | 0.214 |
| 1200 | 0.00025 | 0.00427 | 0.060 |

> **유효 기억 수명 = 80 토큰** (`d=128, p=64, r∈[0.90,0.999]`, 학습 전)

## 13. 살아남은 것 — 잡음이 `Δ` 에 무관하므로 β 가 보존된다

이론 예측은 이랬다. 잡음은 **저장된 모든 항목**이 만들고 최근 항목이 지배하므로, 신호의
`Δ` 와 무관해야 한다. 그러면 `SNR(Δ) ∝ K(Δ)` 이고 지수가 그대로 넘어온다.

| | 로그-로그 지수 (창 Δ∈[20,500]) |
|---|---|
| 신호 `K(Δ)` | 0.849 ± 0.427 |
| **잡음** | **−0.007 ± 0.048** |
| SNR | 0.862 ± 0.436 |

**잡음 지수가 0 이다.** 실측 범위도 `[0.00377, 0.00443]` 으로 최대/최소 1.175 배 — 사실상
상수다 (신호는 237.5 배 변한다).

> **§9-1 의 구멍이 닫혔다. SNR 의 모양은 신호가 정하고, β 는 보존된다.**

**단 지수의 절댓값은 §4 의 해석값(1.485)과 안 맞는다** (0.849 ± 0.427). 원인 셋으로 갈리지
않았다: (a) `p=64` 는 §4 의 연속 극한(`p=4096`)에서 멀다, (b) 창 `[20,500]` 이
`r_max=0.999` 의 유효 구간(≈200)을 넘는다, (c) 실제 커널에는 `|z_t||z_n|cos(ψ+ΔΦ)` 가
붙어 진동한다. **`±0.43` 이라 이 값으로 β 를 주장하면 안 된다.** §4 의 해석 결과는
*포락선의* 지수이고, 그것과 실측 지수의 차이는 미결이다.

## 14. 뒤집힌 것 ① — `r_max` 넓히기는 **아무 효과가 없다**

§5·§11-2 의 예측은 "`r_max` 를 올리면 창이 넓어지고 기억이 길어진다. 개입 비용 0" 이었다.

| 설정 | τ_max | **수명(SNR≥1)** | SNR@Δ=200 |
|---|---:|---:|---:|
| `p=64, r_max=0.999` (현재) | 999 | **80** | 0.572 |
| `p=64, r_max=0.9999` | 9,999 | **80** | 0.579 |
| `p=64, r_max=0.99999` | 99,999 | **80** | 0.579 |
| `p=256, r_max=0.9999` | 9,999 | **80** | 0.804 |

**τ_max 를 100 배 올려도 수명이 1 토큰도 안 늘어난다. 예측 반증.**

### 14.1 왜 — SNR 을 정하는 것은 τ 의 최댓값이 아니라 **긴 채널의 비율**이다

큰 `Δ` 에서 신호는 `τ_j > Δ` 인 채널만 낸다. 그런데 **잡음은 전 채널이 낸다.**
따라서 `SNR(Δ) ∝ (τ_j > Δ 인 채널 수) / √(전체 채널 에너지)` 다.

| 설정 | τ 중앙값 | **τ>80** | **τ>500** | τ_max |
|---|---:|---:|---:|---:|
| `uniform r_max=.999` | 19.3 | **8/64** | 1/64 | 999 |
| `uniform r_max=.9999` | 19.5 | **8/64** | 2/64 | 9,999 |
| `uniform r_max=.99999` | 19.5 | **8/64** | 2/64 | 99,999 |
| **`logtau`** | **97.5** | **35/64** | **10/64** | 999 |

`r` 을 균등 추출하면 `τ = −1/ln r` 이 `r→1` 에서 폭발하므로, `r_max` 를 올려도
**긴 채널의 개수는 그대로고 몇 개가 아주 길어질 뿐이다.** 8/64 가 8/64 로 고정돼 있다.

> **§5.1 에서 "변동폭이 커진다" 는 부작용으로만 적었던 표본 몰림이, 실은 개입 전체를
> 무효화하는 주범이었다.**

## 15. 뒤집힌 것 ② — `logtau` 가 유일하게 듣는 개입이고, 그것은 **거래**다

| Δ | uniform (현재) | uniform `r_max=.99999` | **logtau** |
|---:|---:|---:|---:|
| 1 | **15.873** | 15.677 | 7.875 |
| 12 | 5.989 | 6.005 | 4.003 |
| 50 | 1.969 | 2.054 | 2.960 |
| 128 | 0.811 | 0.801 | **1.437** |
| 200 | 0.572 | 0.579 | **1.420** |
| 500 | 0.214 | 0.250 | 0.671 |
| **수명** | **80** | **80** | **200** |

`r_max=0.9999` 까지 같이 올리면 `logtau` 의 수명은 **500** 까지 간다 (`diag_snr.py [S5]`).
즉 **`logtau` 하에서는 `r_max` 가 듣는다** — 로그 등간격이라 τ_max 를 올리면 긴 채널이
실제로 늘기 때문이다. 두 손잡이가 곱해진다.

### 15.1 공짜가 아니다 — 최근을 팔아 과거를 산다

```
∫ SNR dlogΔ  =  '몇 자릿수의 과거를 몇 배의 신뢰도로 아는가'
```

| 설정 | ∫ 총 | ∫ (Δ≤32) | ∫ (Δ>32) |
|---|---:|---:|---:|
| uniform (현재) | **33.49** | **29.85** | 2.44 |
| uniform `r_max=.99999` | 33.23 | 29.54 | 2.49 |
| **logtau** | 27.56 | 22.19 | **3.84** |

**최근이 26% 줄고 과거가 57% 늘고, 총합은 18% 줄었다.** `SNR@Δ=1` 도 15.87 → 7.88 로
절반이 된다.

> **가소성-안정성 딜레마가 이 구조에서 실측됐다.** Fusi 가 전제한 거래가 실재하며,
> 심지어 약간 손해다 (총합 보존이 아니라 감소).

### 15.2 그래서 `EXTRAPOLATION.md` 와 `CAPACITY.md` 가 동시에 설명된다

| 관측 | 지금까지의 설명 | 거래 관점 |
|---|---|---|
| `EXTRAPOLATION.md §1`: `logtau` 가 외삽을 0.840→0.902 로 **미미하게** 개선 | "반증(미미)" | **예측되는 결과다.** 외삽은 긴 Δ 를 쓰므로 이득이 나고, 거래라서 크지 않다 |
| `CAPACITY.md §4.2`: `τ` 초기화가 **0.68 bpb** 를 결정 | 미결 | **`T=128` LM 은 최근이 지배한다.** 최근 SNR 을 파는 초기화는 bpb 를 잃는다 |

**두 문서의 미결이 한 거래의 양면이었다.**

### 15.3 §6 의 처방은 방향이 반대다 — **철회**

§6 은 `logtau + γ·τ^{−1}` 로 β 를 1.5 로 **복원**하자고 했다. 그런데 §7 의 다이얼이
`β ≈ 1.49 − a` 이고, **β 가 낮을수록 천천히 잊는다.** 즉 그 처방은 `logtau` 가 얻은
수명 이득을 **되돌린다.**

> **장기기억이 목표면 β 를 복원할 것이 아니라 더 낮춰야 한다** (`γ·τ^{+a}`, `a>0`).
> "거듭제곱을 지켜라" 가 목표를 잘못 읽은 것이었다 — 지수 < 거듭제곱 < 로그 순으로
> 느리게 잊으므로, **로그 감쇠가 거듭제곱보다 장기기억에 유리하다.**

`Fusi et al.` 이 거듭제곱을 목표로 삼은 것은 그의 시냅스가 **이산·유계**라 그 이상 못
가기 때문이다. 연속 값 뱅크는 더 갈 수 있다. **§4.1 의 논지와 같은 구조의 오독이었다.**

## 16. β 다이얼을 SNR 로 — 수명 80 → 500, 그리고 **천장이 보인다**

§7 의 다이얼(`진폭 = γ·τ^{+a}`, `β ≈ 1.49 − a`)을 SNR 로 스윕했다. 파라미터 0 개.
`a=0` 은 현재 구조와 정확히 같다 (환원 확인).

| 설정 | **수명** | SNR@Δ=1 | SNR@Δ=200 | ∫ 총 | ∫ (Δ≤32) | **∫ (Δ>32)** |
|---|---:|---:|---:|---:|---:|---:|
| **uniform, `a=0`  (현재)** | **80** | **15.87** | 0.572 | **33.49** | **29.85** | 2.44 |
| uniform, `a=0.5` | 320 | 8.09 | 1.253 | 24.91 | 19.33 | 4.27 |
| uniform, `a=1.0` | 320 | 4.21 | 1.556 | 17.90 | 11.84 | **4.82** |
| logtau, `a=0` | 200 | 7.88 | 1.420 | 27.56 | 22.19 | 3.84 |
| **logtau, `a=0.5`** | **500** | 4.47 | **1.851** | 17.22 | 11.29 | 4.66 |
| logtau, `a=1.0` | 500 | 3.33 | 1.806 | 13.86 | 8.26 | 4.56 |

### 16.1 세 가지가 한꺼번에 나온다

**① 수명이 80 → 500 (6.25배).** 파라미터 0 개, 새 상태 0 개, 초기화 상수만 바꿔서.

**② `a=1.0` 은 이득이 없다.** 수명이 320/500 으로 `a=0.5` 와 같은데 `∫총` 만 더 떨어진다
(24.91→17.90, 17.22→13.86). **`a=0.5` 가 동작점이다.**

**③ 그리고 과거 쪽 예산에 천장이 있다.**

```
∫ (Δ>32) :  2.44 → 4.27 → 4.82        (uniform,  a = 0 → 0.5 → 1.0)
            3.84 → 4.66 → 4.56        (logtau,   a = 0 → 0.5 → 1.0)
```

**무엇을 하든 4.8 근처에서 멈춘다.** `logtau` 와 `a` 를 곱해서 밀어도 안 넘는다.

> **`CAPACITY.md §7` 이 "`O(1)` 상태 클래스 전체의 정보이론적 한계" 라고 부른 벽이
> 처음으로 숫자로 나왔다.** 장거리 회상 예산의 천장이 `∫SNR dlogΔ ≈ 4.8` 이고,
> **현재 기본 설정은 그 절반(2.44)만 쓰고 있다.**

### 16.2 그래서 지금 할 수 있는 것과 없는 것이 갈린다

| | |
|---|---|
| **공짜로 얻을 수 있는 것** | 천장까지의 **2 배** — 수명 80 → 320~500. 초기화만 바꾸면 됨 |
| **거래해야 하는 것** | 그 대가는 최근 SNR 15.87 → 4.47. 태스크가 어느 쪽을 쓰는지가 정함 |
| **어떤 개입으로도 못 넘는 것** | `∫(Δ>32) ≈ 4.8`. 여기서 더 가려면 **상태를 키우는 수밖에 없다** |

세 번째 줄이 `MISALIGNMENT.md §6.4` 의 "정직한 한계" 를 정량화한 것이다 — 거기서
*"`W` 를 더해도 상태는 `O(1)` 이고 얻는 것은 비트가 아니라 배분"* 이라고 썼는데,
**그 배분의 총량이 4.8 이고 지금 2.44 를 쓰고 있다는 것**까지 이제 안다.

## 17. 개정된 다음 수

§11 을 대체한다. **§11 의 1(SNR)은 완료, 2(창 넓히기)는 반증, 3(처방)은 철회,
4(β 스윕)는 §16 에서 완료.** 남은 것은 전부 **학습이 필요한** 항목이다.

1. **동작점을 태스크가 정하게 하기.** 거래인 이상 "최선의 β" 는 없고 **태스크가 요구하는
   `Δ` 분포**가 정한다. 결정적 시험: `logtau + a=0.5` 로 (a) `T=128` LM — **져야 한다**
   (최근을 팔았으므로), (b) 길이 외삽 — **이겨야 한다**. **둘 다 이기면 거래 해석이
   틀린 것이고, 둘 다 지면 SNR 이 태스크 성능의 대리지표가 아닌 것이다.**
2. **`∫(Δ>32) ≈ 4.8` 천장이 `p` 에 어떻게 스케일하는지.** `O(1)` 벽의 계수를 재는 것이다.
   `p = 32/64/128/256` 스윕. 학습 불필요. 만약 `∝ √p` 면 SNR 이론과 맞고, `∝ p` 면
   다른 일이 벌어지고 있다.
3. **갈래 C 의 막이 이 거래를 움직이는지.** `gate_write` 는 쓰기를 선택적으로 만드므로
   **간섭(잡음)을 줄일 수 있다** — 지금까지 잰 개입은 전부 신호 쪽만 건드렸다.
   잡음을 줄이면 거래 없이 천장을 올릴 수 있는 유일한 경로다. `MISALIGNMENT §9.9.4` 의
   직접 사영 게이트 대조군과 **같은 실험으로 둘 다 답할 수 있다.**
4. **`W`(개입 6)는 `#5` 전용으로 격하.** §2.1 대로 상승상·앨리어싱에만 쓴다.

3 번이 가장 값지다. **신호 쪽 다이얼은 오늘 다 돌렸고 천장을 봤다. 남은 방향은 잡음이다.**
