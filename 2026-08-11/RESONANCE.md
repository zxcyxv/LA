# 이 구조는 STDP 가 아니라 resonate-and-fire 다

> **이 문서의 용도.** `PLASTICITY.md` 는 이 구조를 STDP(spike-timing-dependent plasticity)
> 틀로 읽는다. 그 틀에는 **"서로 다른 두 뉴런"** 이 있어야 하는데, 이 모델에서 그것이
> 어디인지 물으면 후보가 둘이고 **둘 다 STDP 의 요건을 못 채운다.** 대신 정확히 맞는
> 틀이 따로 있다 — Izhikevich (2001) 의 **resonate-and-fire**.
>
> 재현: `python diag_resonance.py` (결맞음·주파수 응답), `python check_stdp_under_C.py`
> (갈래 C 가 위상 해석을 깨는지). 둘 다 학습 불필요.

---

## 0. 한 장 요약

| 발견 | 상태 |
|---|---|
| "두 뉴런" 의 후보가 둘이고 **둘 다 결함**이 있다 (A: 시냅스 O·타이밍 X / B: 타이밍 O·시냅스 X) | 확정 §1 |
| **`PLASTICITY.md` 가 두 독법을 절마다 바꿔 쓴다** — §1·§6.1 은 A, §2·§3·§5.3 은 B | **비정합** §1.2 |
| 실제로는 "두 뉴런" 이 아니라 **한 채널의 두 시각** — 자기상관이다 | 확정 §2 |
| 전이식 `S_t[j] = e^{−α_j+iθ_j}S_{t-1}[j] + …` 이 **R&F 방정식 그 자체**다 | 확정 §2.1 |
| 위상차가 **작을수록**이 아니라 **`ψ_j` 와 같을 때** 공진한다 (각분리 π = 부호 반전) | 정정 §3 |

핵심 문장:

> 이 모델은 STDP 를 어설프게 흉내낸 것이 아니라 **resonate-and-fire 를 정확히 구현**하고
> 있다. 그런데 R&F 의 정의적 성질인 **주파수 선호를 아직 못 쓰고 있다** — 공진 대역이
> 불응기 안에 갇혀 있기 때문이다.

## 1. "두 뉴런" 이 어디 있나

쓰기 규칙을 지표까지 펼치면 `ΔS_t[j,e] = k_{t,j} · v_{t,e}` 이고, `S` 는 `p×d` 다.

### 독법 A — pre = 복소 채널 `j`, post = 은닉 차원 `e`

`PLASTICITY.md §1` 의 대응표가 이것이다. `S[j,e]` 는 뉴런 `j`→`e` 의 시냅스이고,
**지속되며 추론 중 갱신된다. 진짜 시냅스다.**

**그러나 `k_{t,j}` 와 `v_{t,e}` 가 같은 `h_t` 에서 같은 시각에 나온다.** `Δt = 0` 이다.
`PLASTICITY §6.1` 이 실측한 그것이다 — *"둘 다 같은 `h_t` 의 함수다"*. **타이밍이 없다.**

### 독법 B — pre = 토큰 `n`, post = 토큰 `t`

`PLASTICITY.md §5.3` 이 명시적으로 채택한다 — *"`n` 이 쓰고(pre), `t` 가 읽음(post)"*.
**시간차 `Δ = t−n` 이 있다.**

**그러나 `a_tn` 은 어디에도 저장되지 않는다.** `q_t` 와 `k_n` 으로 매번 재계산되고,
갱신되는 `w_ij` 가 없으며, 토큰은 시간을 가로질러 존재하는 단위가 아니다.
**이 층위의 "가소성" 은 가소성이 아니라 어텐션 가중이다.**

### 1.1 어느 쪽도 STDP 가 아니다

| | 시냅스가 지속·갱신되는가 | 시간차가 있는가 |
|---|---|---|
| **A** (채널 `j` → 차원 `e`) | **○** | **✗** |
| **B** (토큰 `n` → 토큰 `t`) | **✗** | **○** |

### 1.2 그리고 문서가 둘을 섞어 쓴다

| 위치 | 독법 |
|---|---|
| `PLASTICITY.md §1` 헤비안 대응표 | **A** |
| `PLASTICITY.md §2` 가소성 창 `ā(Δ)` | **B** |
| `PLASTICITY.md §3` `ψ` 대칭/반대칭 분해 | **B** |
| `PLASTICITY.md §5.3` 역할/부호 분리 | **B** |
| `PLASTICITY.md §6.1` "post 항이 없다" | **A** |

§6.1 이 "post 가 없다" 고 말할 수 있는 것은 A 를 쓰기 때문이고, §5.3 이 "역할은 토큰
순서가 정한다" 고 말할 수 있는 것은 B 를 쓰기 때문이다. **같은 문서에서 층위가 바뀐다.**

`MISALIGNMENT.md §3` 의 어긋남 `#2`("비대칭이 쓰기가 아니라 읽기 커널에 있다 — 한 사상 옆")
가 절반을 짚었지만, **두 독법을 병용하고 있다는 데까지는 안 갔다.**

## 2. 실제로는 "한 채널의 두 시각" 이다

읽기를 펼치면 무엇이 곱해지는지 보인다.

```
f_t = Re[q_t† S_t] = Σ_n Σ_j  conj(q_{t,j}) · λ_j^{t−n} · k_{n,j} · v_{n,e}
                              └─ 채널 j, 시각 t ─┘      └─ 채널 j, 시각 n ─┘
```

**같은 채널 `j` 가 시각 `t` 와 `n` 에 두 번 등장한다.** 커널도 마찬가지다:

```
a_tn = p^{−1/2} Σ_j γ_j |z_tj||z_nj| e^{−α_jΔ} cos( arg z_nj − arg z_tj − ψ_j − ΔΦ_j )
                          ↑ 채널 j 의 시각 t 와 n 을 비교 = 자기상관
```

`PLASTICITY §6.1` 의 마지막 줄이 이미 정확히 적어놓았다 —
*"엄밀히는 헤비안도 아니고 **입력 자기상관 누적**이다."*

### 2.1 그리고 전이식이 R&F 방정식 그 자체다

Izhikevich (2001) 의 resonate-and-fire:

```
R&F  :  ż = (−b + iω) z + I(t),      z = V + iW ∈ ℂ,   Re z > θ 면 발화
모델  :  S_t[j] = e^{−α_j + iω_{t,j}} S_{t-1}[j] + γ_j k_{t,j} v_t†
```

`e^{(−α+iθ)Δt}` 가 `ż = (−α+iθ)z` 의 이산화다. **같은 식이다.**

| R&F | 이 모델 |
|---|---|
| `b` 감쇠 | `α_j` (`τ_j = 1/α_j`) |
| `ω` 고유 진동수 | `θ_j` (주기 `2π/θ_j`) |
| `z` 복소 상태 | `S_t[j,:]` — 스칼라가 아니라 `d` 차원 복소 벡터 |

R&F 가 integrate-and-fire 와 다른 점 넷 — 문턱하 진동, **주파수 선호**, 위상에 따른 상쇄,
**억제가 발화를 유발** — 중 마지막 것이 `PLASTICITY §5.3` 의 "모든 lag 에서 LTP:LTD =
44:56" 이다. **음의 기여가 절반인 것은 버그가 아니라 R&F 의 정의적 성질이다.**

### 2.2 층위 구조

```
① 진동자층 (S)   R&F — 감쇠 회전 + 입력 주입
② 검출층 (f)     호모다인 — 현재 위상 vs 저장된 위상, ψ_j 가 기준점
③ 포화층 (a_tt)  3차. 개입 1 로 음수 보장 → 진폭 상한
④ 막층 (m,s,a)   IF — 적분 → 문턱 → 불응    ← 갈래 C
```

**①②는 R&F 이고 ④는 IF 다.** 진짜 R&F 는 진동과 문턱이 같은 변수에 있다(`Re z > θ`).
여기서는 진동이 `S`, 문턱이 `m` 이다.

`MISALIGNMENT §9.7` 은 이것을 한계로 적었다 — *"`h` 에 문턱을 만든 게 아니라 새 변수
`m` 에 만들었다"*. **R&F 프레임에서는 한계가 아니라 수상돌기/세포체 분리다**
(공진하는 수상돌기 → 적분하는 세포체 → 축삭 발화). `RESULTS.md §8.4` 가 언급한
"dendritic R&F" 가 그것이다.

## 3. 정정 — 위상차가 "작을수록" 이 아니다

공진 조건은 `위상차 ≈ 0` 이 아니다. `RESULTS.md §3.2` 의 유도해는 `φ_q − φ_k = c·N` 이고
**0 이 아니다.** 그리고 §3.5 의 실측에서 **각분리가 정확히 π** 로 나왔다.

| 위상차 | cos | 의미 |
|---|---|---|
| `ψ_j` 와 일치 | +1 | 정답 — 강하게 읽음 |
| `ψ_j + π` | −1 | 오답 — 강하게 **뺌** |
| 무작위 | ≈0 | 무관 — 상쇄 |

**`ψ_j` 는 헤비안↔STDP 다이얼이 아니라 호모다인 검출의 국소발진기 위상이다** —
어느 직교성분(quadrature)을 측정할지 고르는 값이고, 채널이 "위상 몇 도를 정답으로 볼지"
정하는 튜닝 다이얼이다. 이 이름으로 부르면 "각분리 π = 부호 반전 = 최적 판별" 이
자연스럽게 읽힌다.

## 4. 보강간섭이 스파이킹을 일으킨다 — 문턱이 8.1 배로 증폭

`diag_resonance.py [R1]`. 같은 에너지·같은 펄스 개수(8개)·같은 위치, **부호만** 바꾼다.
결맞음 = 전부 `+v`, 무작위 = `±v` (8회 평균).

| 진폭 | Δm 결맞음 | Δm 이득 | **s 결맞음** | **s 무작위** | **스파이크 이득** |
|---:|---:|---:|---:|---:|---:|
| 0.5 | 0.0869 | 1.57× | 0.0003 | 0.0001 | 3.0× |
| 1.0 | 0.1734 | 1.62× | 0.0033 | 0.0005 | 6.6× |
| **2.0** | **0.3650** | **2.00×** | **0.3831** | **0.0471** | **8.1×** |
| 4.0 | 0.5284 | 1.34× | 0.9819 | 0.2588 | 3.8× |
| 8.0 | 0.4882 | 1.09× | 0.9476 | 0.2757 | 3.4× |

> **막전위 이득이 2 배인데 스파이크 이득이 8.1 배다. 문턱이 결맞음 검출기로 작동한다.**

### 4.1 단 좁은 대역에서만

`amp=2.0` 에서 이득이 최대다. 너무 약하면 둘 다 안 터지고(0.0003 vs 0.0001), 너무 세면
둘 다 터진다(0.95 vs 0.28). **문턱이 걸쳐 있는 구간에서만 결맞음이 판별된다** —
생물학의 동작점 개념이 그대로 나타난다.

### 4.2 완전한 결맞음은 아니다

이론상 8 개가 완전히 결맞으면 `√8 = 2.83` 배여야 하는데 실측 최대가 **2.00** 이다.
**커널이 lag 에 따라 회전하기 때문이다** — 같은 벡터를 넣어도 위상이 돌아가 완전히
겹치지 않는다. `MISALIGNMENT [D]` 의 "40토큰에 부호 반전 36회" 가 이 손실이다.

## 5. 회전 주기가 불응기보다 짧다 — R&F 의 핵심 성질이 막혀 있다

`diag_resonance.py [R2]` 를 돌리다 나온 것이다.

```
θ 주기 2π/θ 의 [10, 50, 90]분위 = [1.15,  2.45,  11.76] 토큰
절대 불응기 (MISALIGNMENT [C3])   = 3 토큰
```

**공진하려면 자극 주기가 회전 주기와 맞아야 하는데, 그 대역(≈2.45)이 불응기(3) 안에
통째로 들어가 있다.** 실측에서도 `T_stim = 1,2` 에서 `Δm` 이 0.0005, 0.0010 으로 죽고
(불응기), `T_stim ≥ 12` 에서는 0.14, 0.11, 0.14, 0.099 로 평평하다(공진 없음).

> **R&F 의 정의적 성질인 주파수 선호를 원리적으로 못 쓰고 있다.**

그리고 이것은 `EXTRAPOLATION.md §3.3` 의 앨리어싱 문제와 **같은 원인**이다 — 거기서도
범인이 "θ 주기 중앙값 2.11 토큰" 이었다. **회전이 너무 빠르다. 한 원인이 두 증상을 만든다.**

**검증 가능한 처방:** `theta_max` 를 낮춰 회전을 느리게 하면 (a) 공진 대역이 불응기
밖으로 나오고 (b) 앨리어싱이 줄고 (c) 길이 외삽이 늘어야 한다. **파라미터 0 개, 예측 3 개.**

**주의:** `[R2]` 의 `s` 열은 위치마다 기저 `m` 이 달라 오염됐다. `Δm` 만 읽어야 한다.
그리고 `T_stim ≤ 3` 의 저하는 공진이 아니라 불응기가 만든 것이므로, **`[R2]` 는 공진의
부재를 증명하지 못한다** — 공진을 잴 수 없는 조건이라는 것만 보인다.

## 6. 갈래 C 는 위상 해석을 깨지 않는다

`check_stdp_under_C.py`. `gate_write` 가 `PLASTICITY §5.3` 의 "부호는 위상이 정한다" 를
깨는지 확인했다.

| 확인 | 실측 |
|---|---|
| 커널 `A` 가 게이트를 받는가 | `max|A_gated − A_nogate| = 0.0e+00` — **안 받는다** |
| 게이트 `g` 의 범위 | `[0.500000, 0.999989]` — **음수 0 개** |
| 같은 `h` 에서 기여 부호 일치 | **100.0000%** (1,327,104 개 전부) |
| lag 별 LTP/LTD 비율 변화 | **0.0000 %p** (Δ=1,3,5,10,20 전부) |

게이트는 value 경로에만 걸리고(`f = A(g⊙h)`) `g > 0` 이 구조적으로 보장되므로,
**양의 스칼라는 부호를 뒤집을 수 없다. 정리다.**

### 6.1 오염되는 것 하나

유효 연산자가 `K_tn·g_n` 이 되면 `t↔n` 교환에서 `g_n → g_t` 라 **정확한 교환 반대칭이
깨진다.** 단 `PLASTICITY §3.5` 가 이미 감쇠 `e^{∓αΔ}` 에 대해 같은 오염을 인정했으므로
새로운 종류는 아니다. **오염 크기는 학습된 모델에서 재야 한다** — 초기화 시점에는
`g ≈ g_floor = 0.5` 로 거의 상수라 측정력이 없다 (반대칭 비중 20.5% → 20.4%).

### 6.2 그리고 post 항이 생겼다

`PLASTICITY §6.1` 이 "post 항이 없다" 고 진단한 자리다. `gate_write` 하에서
`ΔS_t = k_t ⊗ (g_t ⊙ h_t)` 이고 `g_t ← s^{(r-1)} ← m ← f^{(r-1)}` = **이전 깊이 단계의 출력**이다.

```
깊이축 : h^(r) 를 1% 흔들면 s^(r) 가 변하는가 → max|Δs| = 7.18e-01   (≠ 0)
```

**쓰기가 출력에 의존하게 됐다.** 단 `§6.2` 가 표로 적었듯 **깊이축에서만**이다 —
시퀀스축 스캔 내부에서는 `s_prev` 가 스캔 시작 전 확정된 상수라 여전히 post 가 없고,
그것이 병렬성의 대가다.
