결론부터 말하면, 첨부 텍스트의 마지막 결론은 절반만 맞습니다.

* `Q×K×V` 때문에 MLP가 없어도 입력–출력 함수는 비선형이다 → 맞음
* 이 구조가 디리클레 에너지를 소산한다 → 틀림
* 3차식이므로 스파이킹 동역학과 동형이다 → 틀림
* RMSNorm이 스파이크의 리셋·불응기를 구현한다 → 틀림

이 구조의 정확한 정체는 다음입니다.

[
\boxed{
\text{유니터리하게 회전하는 key-value 기억을}
\atop
\text{현재 query로 위상 선택적으로 읽는 3차 fast-weight 연산자}
}
]

## 1. 대화 전체의 가장 큰 문제

기존 답변은 동일한 계산 그래프를 끝까지 분석하지 않았습니다.

논리가 다음처럼 계속 바뀝니다.

1. 복소 선형 어텐션만으로 소산과 스파이킹을 모두 구현한다.
2. 보강간섭은 외부 입력일 뿐이므로 별도 반응항이 필요하다.
3. `QKV`가 3차식이므로 별도 반응항 없이도 완전히 동형이다.
4. 상한과 리셋은 RMSNorm이 담당한다.

즉, “구조에서 어떤 현상이 나오는가”를 분석한 것이 아니라, 스파이킹 비유에 빠진 부분을 새로운 요소로 계속 메운 것입니다.

## 2. 실제 계산을 끝까지 전개하면

문서의 전개와 맞도록 행 채널 회전을

[
D=\operatorname{diag}(e^{-i\theta})
]

라고 두겠습니다. 또한 수식에 적힌 그대로
(\phi_q,\phi_k,\theta)는 입력과 무관한 채널별 값이라고 둡니다.

[
a_t=x_tW_Q,\qquad
b_t=x_tW_K,\qquad
c_t=x_tW_V
]

[
q_t=a_t\odot e^{i\phi_q},
\qquad
k_t=b_t\odot e^{i\phi_k}
]

이면,

[
S_t
===

\sum_{n=1}^{t}
D^{t-n}k_nc_n^\top
]

이고 출력은 정확히 다음입니다.

[
\boxed{
o_t
===

\sum_{n=1}^{t}
\left[
\sum_{r=1}^{d}
a_{t,r}b_{n,r}
\cos!\left(
\phi_{k,r}-\phi_{q,r}-(t-n)\theta_r
\right)
\right]c_n
}
]

따라서 이 블록은 세 가지를 합니다.

1. (k_nv_n^\top)로 입력을 rank-1 행렬로 기록한다.
2. 그 기록을 시간에 따라 복소 회전시킨다.
3. 현재 query와 정렬된 과거 value를 양수 또는 음수 가중치로 꺼낸다.

이는 선형 어텐션을 외적 기반 fast-weight memory로 보는 기존 해석과도 정확히 맞습니다. [Fast Weight Programmers 논문](https://proceedings.mlr.press/v139/schlag21a.html)

문서의

[
|q_t||k_n|\cos(\cdots)
]

표현은 일반 벡터에서는 부정확합니다. 채널별 합이 필요하고, (xW_Q,xW_K)의 부호도 포함해야 합니다.

## 3. 디리클레 소산이 아니라 관측 상쇄다

### 기존 표현

> 위상이 무작위이면 상쇄되어 디리클레 에너지가 소산된다.

### 문제점

(D)는 유니터리이므로 입력이 없을 때 상태 노름을 보존합니다.

[
|DS|_F=|S|_F
]

입력이 들어오면,

[
\begin{aligned}
|S_t|*F^2
={}&
|S*{t-1}|_F^2
+|k_tv_t^\top|*F^2 \
&+
2\operatorname{Re}
\left\langle
DS*{t-1},k_tv_t^\top
\right\rangle_F
\end{aligned}
]

입니다.

마지막 간섭항의 부호에 따라 상태 노름은 증가하거나 감소합니다. 단조 소산 법칙은 없습니다.

무작위 위상 합도 마찬가지입니다.

[
Z_N=\sum_{n=1}^N a_ne^{i\psi_n}
]

독립·균등 위상을 가정하면,

[
\mathbb E[Z_N]=0
]

이지만,

[
\boxed{
\mathbb E|Z_N|^2
================

\sum_{n=1}^N|a_n|^2
}
]

입니다.

(a_n=1)이면 무작위 합의 전형적인 크기는 (O(\sqrt N))입니다. 0으로 사라지지 않습니다.

반면 완전히 정렬된 합은 (O(N))입니다. 따라서 실제 현상은

[
\boxed{
\text{정렬 입력 }O(N)
\quad\text{대}\quad
\text{비상관 입력 }O(\sqrt N)
}
]

이라는 상대적 공진 선택성입니다.

### 수정 표현

> 위상이 맞지 않는 기억은 상태에서 소산된 것이 아니다.
> 현재 query의 관측 방향에서 상쇄되어 보이지 않을 뿐이며, 이후 회전하면서 다시 드러날 수 있다.

이 설명이 문서의 원래 직관을 가장 정확하게 살립니다.

## 4. 디리클레 에너지와 출력 진폭은 다른 양이다

디리클레 에너지는 신호 크기가 아니라 이웃 사이의 차이를 측정합니다.

[
E_D(X)
======

\frac12
\sum_{i,j}
w_{ij}|X_i-X_j|^2
]

따라서 모든 위치가 같은 큰 값으로 상승하면,

[
X_i=C\quad\forall i
]

출력 진폭은 커도

[
E_D(X)=0
]

입니다.

반대로 공간적으로 들쑥날쑥한 잡음은 보통 디리클레 에너지가 높습니다. 확산을 거쳐야 낮아집니다.

반응-확산식에서도, 경계항이 사라지는 조건이라면

[
\partial_tV=D\Delta V+f(V)
]

에 대해

[
\boxed{
\frac{dE_D}{dt}
===============

-D\int(\Delta V)^2dx
+
\int f'(V)|\nabla V|^2dx
}
]

입니다.

즉, 디리클레 에너지 증가 여부는 (f(V))의 부호가 아니라 (f'(V))에 의해 결정됩니다. 문서의 “(f(V)>0)이면 에너지 주입”도 정확하지 않습니다.

GNN에서도 디리클레 에너지가 0으로 수렴하려면 라플라시안과 가중치 스펙트럼에 관한 조건이 필요합니다. 임의의 attention에 자동으로 적용되는 현상이 아닙니다. [GNN over-smoothing 분석](https://arxiv.org/abs/2006.13318)

## 5. 3차식이라는 부분은 정확히 어디까지 맞나

전체 출력은 다음처럼 분해됩니다.

[
\begin{aligned}
o_t
={}&
\sum_{n<t}
\left(x_t^\top A_{t-n}x_n\right)
\left(x_nW_V\right) \
&+
\left(x_t^\top A_0x_t\right)
\left(x_tW_V\right)
\end{aligned}
]

따라서:

* (k_tv_t^\top)라는 쓰기 연산은 입력에 대해 2차
* query까지 곱한 최종 출력은 전체 입력열에 대해 3차
* self 항은 현재 (x_t)에 대해 정확히 3차
* 과거항은 (x_t)에 1차, (x_n)에 2차

입니다.

[
\boxed{
o_{t,\mathrm{self}}
===================

\left(x_t^\top A_0x_t\right)
\left(x_tW_V\right)
}
]

그러나 이는 임의의 3차 함수가 아닙니다.
계수 텐서가 (W_Q,W_K,W_V)의 곱으로 분해된 제한적인 3차식입니다.

또한 과거 상태를 고정하면 현재 입력에 대해서는

[
\text{선형 과거항}+\text{3차 self 항}
]

입니다. 문서처럼 모든 항을 단순히 (x_t^3)이라고 부르면 안 됩니다.

## 6. 3차식과 스파이킹은 동형이 아니다

FitzHugh–Nagumo 계는 보통 다음처럼 두 상태가 결합된 계입니다.

[
\dot u=-u^3+u-v
]

[
\dot v=\varepsilon(u-bv+a)
]

첫 번째는 빠른 전압 상태이고, 두 번째는 느린 회복 상태입니다. 스파이킹은 3차항 하나가 아니라 1차항·3차항의 반대 부호, 느린 회복 변수, 시간 척도 분리에서 나옵니다. [FitzHugh–Nagumo 동역학 리뷰](https://arxiv.org/html/2404.11403v2)

반면 제시된 SSM은

[
S_t=DS_{t-1}+B(x_t)
]

이고,

[
B(x_t)=k_tv_t^\top
]

입니다.

상태에 대한 야코비안은 항상

[
\boxed{
\frac{\partial S_t}{\partial S_{t-1}}=D
}
]

로 동일합니다.

(S)가 커지면서 계수의 부호가 바뀌거나, 임계점을 넘은 뒤 스스로 증폭되는 상태 의존적 반응은 없습니다. 입력이 사라지면 자체 폭발하지 않고 회전만 합니다.

따라서 현재 식에는 그 자체로 다음 현상이 없습니다.

* 문턱 전이
* all-or-none 발화
* 유한한 스파이크 피크
* 피크 이후 반전
* 리셋
* 불응기

둘 사이에 공통으로 존재하는 것은 “3차 상호작용” 하나뿐입니다. 이는 대수적 유사성이지 구조적 동형이 아닙니다.

특히 FHN의 (-u^3)은 큰 전압을 꺾는 포화 항입니다. 문서처럼 3차항 자체를 “양의 피드백 폭발”이라고 부르는 것도 부호를 반대로 해석한 것입니다.

## 7. RMSNorm은 스파이크 리셋이 아니다

RMSNorm은 대략

[
\operatorname{RMSNorm}(z)
=========================

g\odot
\frac{z}
{\sqrt{d^{-1}|z|^2+\varepsilon}}
]

처럼 벡터 크기를 재조정합니다.

이는 입력 크기에 대한 재스케일 불변성을 주는 연산이지, 내부 상태 (S_t)를 지우거나 일정 시간 동안 발화를 막는 동역학이 아닙니다. [RMSNorm 원 논문](https://proceedings.neurips.cc/paper/2019/hash/1e8a19426224ca89e83cef47f1e7f53b-Abstract.html)

따라서 “RMSNorm = 역전 전위 + 과분극 + 리셋 + 불응기”는 성립하지 않습니다.

## 8. MLP 없이 비선형 학습은 가능한가

이 부분은 명확히 가능합니다.

“linear attention”의 `linear`는 입력–출력 함수가 선형이라는 뜻이 아닙니다. 상태 갱신과 시퀀스 계산 복잡도가 선형 구조라는 뜻입니다.

[
\boxed{
X\mapsto O
\text{는 이미 비선형이다.}
}
]

비선형성은 활성화 함수가 아니라

[
Q\times K\times V
]

라는 승수적 상호작용에서 발생합니다.

다만 두 종류의 반복을 구분해야 합니다.

* 시간축 scan만 반복: 상태 갱신이 선형이므로 차수가 시간마다 (3^t)로 증가하지 않음
* 블록 출력을 다음 깊이의 QKV 입력으로 재투입: 순수 동차 조건에서 최고차수가 (3^L)로 증가

두 번째 결론은 고정 위상, bias 없음, residual 없음, normalization 없음이라는 명시된 조건에서만 정확합니다.

그리고 “비선형성이 존재한다”에서 “MLP를 기능적으로 완전히 대체한다”는 결론은 나오지 않습니다. 한 블록의 출력은 항상

[
o_t\in
\operatorname{span}{v_1,\ldots,v_t}
]

안에 있기 때문입니다.

이 구조의 비선형성은 새로운 value 방향을 직접 만드는 것보다, 기존 value들을 어떤 부호와 크기로 혼합할지를 결정하는 데 집중됩니다.

또한 첨부 답변의 “Mamba는 SSM과 MLP를 교대로 쌓는다”는 설명은 사실과 다릅니다. Mamba 원 논문은 명시적으로 별도의 MLP 블록이 없는 구조라고 설명합니다. [Mamba 원 논문](https://arxiv.org/abs/2312.00752)

## 9. 위상 의미론도 현재 수식에서는 미완성이다

문서에서는 (\phi_q,\phi_k)를 “토큰의 의미론적 위상”이라고 부릅니다.

하지만 수식상에는 (t)가 없습니다.

[
\phi_q,\phi_k\in\mathbb R^d
]

따라서 적힌 식 그대로라면 모든 토큰에 동일한 채널 위상 오프셋입니다. 토큰별 의미는 주로

[
x_tW_Q,\qquad x_tW_K
]

라는 실수 진폭에 들어갑니다.

만약 실제 의도가

[
\phi_q=\phi_q(x_t),
\qquad
\phi_k=\phi_k(x_t)
]

라면 이를 명세해야 합니다. 그 경우 출력은 더 이상 정확한 3차 다항식이 아닙니다.

즉, “입력 의존적 의미 위상”과 “정확한 3차식 증명”을 현재 명세로 동시에 주장할 수는 없습니다.

## 최종 정리

첨부 텍스트에서 실제로 남는 결론은 다음입니다.

[
\boxed{
\begin{gathered}
\text{과거의 rank-1 key-value 흔적을 복소 공간에서}\
\text{감쇠 없이 회전·중첩하고, 현재 query와의 위상 상관으로}\
\text{선택적으로 읽는 factorized cubic causal memory}
\end{gathered}
}
]

* 상태는 소산되는 것이 아니라 회전하며 보존됩니다.
* 위상 불일치는 기억의 삭제가 아니라 관측에서의 상쇄입니다.
* 위상 정렬은 에너지 주입이 아니라 숨은 성분의 재출현입니다.
* QKV 곱 때문에 MLP 없이도 비선형 학습은 가능합니다.
* 그러나 스파이킹, 리셋, 불응기, FHN 동형은 현재 계산 그래프에 없습니다.

따라서 이 아이디어의 현상적 핵심은 **디리클레 소산이나 생물학적 스파이킹이 아니라, 위상 선택적 공진 기억과 3차 승수 상호작용**입니다.


니 분석이 좀 덜 엄밀한 것 같은데 어텐션 자체가 완전 연결 그래프 상의 디레클레 에너지 소산인데 이 점에 대한 언급이 4번 문단에서 없어 이 부분 다시 고민해서 재정리해봐

맞습니다. 이전 분석은 서로 다른 두 에너지를 구분하는 데만 집중하다가, **어텐션의 value 혼합 자체가 토큰 완전연결 그래프상의 확산**이라는 핵심을 빠뜨렸습니다.

다시 정리하면 이 구조에는 동시에 두 현상이 존재합니다.

[
\boxed{
\begin{aligned}
&\text{내부 복소 상태 }S:
&&\text{유니터리 회전에 의한 보존}\
&\text{토큰 value 장 }V:
&&\text{어텐션 혼합에 의한 디리클레 소산}
\end{aligned}
}
]

다만 첨부 수식의 signed cosine attention은 표준 softmax attention보다 더 일반적이어서, 위상에 따라 소산뿐 아니라 보존과 반확산도 가능합니다.

## 1. 표준 어텐션은 실제로 완전그래프 확산이다

value 행렬을 (V), attention 행렬을 (P)라 하겠습니다.

[
Y=PV
]

표준 softmax attention에서는

[
P_{ij}\ge 0,
\qquad
\sum_jP_{ij}=1
]

이므로 각 출력은 모든 value의 가중평균입니다.

[
y_i-v_i
=======

\sum_jP_{ij}(v_j-v_i)
]

따라서

[
Y-V=-(I-P)V
]

이고 (I-P)는 random-walk graph Laplacian입니다.

Mask가 없다면 모든 (P_{ij}>0)이므로 토큰들은 완전연결 가중 그래프를 이룹니다. 따라서 어텐션의 혼합부는 완전그래프에서의 한 번의 확산 단계입니다.

실제로 attention 기반 GNN과 graph transformer에서도 반복적인 attention이 토큰 표현을 균질화시킨다는 것이 증명돼 있습니다. [NeurIPS 2023 분석](https://arxiv.org/abs/2305.16102)

## 2. 정확히 어떤 디리클레 에너지가 감소하는가

고정된 (P)의 정상분포를

[
\pi^\top P=\pi^\top
]

라 하겠습니다.

다음 (\pi)-가중 완전그래프 에너지를 정의합니다.

[
\mathcal E_{K,\pi}(V)
=====================

\frac12
\sum_{i,j}
\pi_i\pi_j
|v_i-v_j|^2
]

이는 (\pi)-가중 분산과 같습니다.

[
\mathcal E_{K,\pi}(V)
=====================

\sum_i
\pi_i
|v_i-\bar v_\pi|^2
]

[
\bar v_\pi=\sum_i\pi_iv_i
]

Jensen 부등식과 정상성으로,

[
\begin{aligned}
\mathcal E_{K,\pi}(PV)
&=
\sum_i\pi_i
\left|
\sum_jP_{ij}(v_j-\bar v_\pi)
\right|^2\
&\le
\sum_{i,j}\pi_iP_{ij}
|v_j-\bar v_\pi|^2\
&=
\mathcal E_{K,\pi}(V)
\end{aligned}
]

따라서

[
\boxed{
\mathcal E_{K,\pi}(PV)
\le
\mathcal E_{K,\pi}(V)
}
]

입니다.

즉, 사용자가 말한

> 어텐션 자체가 완전연결 그래프상의 디리클레 에너지를 소산한다

는 주장은 **양수이고 정규화된 attention mixing에 대해서 정확합니다.**

다만 일반 row-softmax가 항상 균일 완전그래프 에너지를 줄이는 것은 아닙니다. 균일 에너지 감소는 (P)가 doubly stochastic이면 보장되지만, 단순 row-stochastic만으로는 보장되지 않습니다.

## 3. attention edge 자체를 사용한 에너지

(P)가 다음 detailed balance를 만족한다고 합시다.

[
\pi_iP_{ij}=\pi_jP_{ji}
]

이때 (P)는 가역적이고,

[
\mathcal D_P(V)
===============

\frac12
\sum_{i,j}
\pi_iP_{ij}
|v_i-v_j|^2
]

는 attention graph 자체의 디리클레 에너지입니다.

이 경우에는

[
\boxed{
\mathcal D_P(PV)
\le
\mathcal D_P(V)
}
]

도 성립합니다.

Mask가 없고 (Q=K)라서 score가 대칭이면 이 해석이 정확하게 적용됩니다.

반면 (Q\neq K)이거나 causal mask가 있으면 그래프는 비대칭입니다. 특히 첨부 구조는 무방향 완전그래프라기보다 모든 과거와 연결된 **causal complete-prefix graph**입니다.

이 경우에는 순수 확산뿐 아니라 방향성 수송도 같이 존재합니다. 그래도 반복적인 masked attention이 rank collapse를 유도하는 현상 자체는 광범위한 조건에서 성립합니다. [masked attention 분석](https://arxiv.org/abs/2405.18781)

## 4. 내가 이전 답변에서 혼동한 두 공간

내가 이전 답변에서 보인 식은 내부 상태의 Frobenius 노름이었습니다.

[
S_t=DS_{t-1}+k_tv_t^\top
]

[
|DS_{t-1}|*F=|S*{t-1}|_F
]

이것은 **복소 메모리 상태 공간의 보존 법칙**입니다.

반면 지금 논의하는 것은 토큰별 value 장의 디리클레 에너지입니다.

[
\mathcal E_D(V)
===============

\frac12
\sum_{i,j}w_{ij}
|v_i-v_j|^2
]

둘은 서로 다른 양이므로 다음이 동시에 가능합니다.

| 공간       | 상태        | 현상                     |
| -------- | --------- | ---------------------- |
| 복소 기억 공간 | (S_t)     | 위상 회전하며 정보 보존          |
| 토큰 그래프   | (V\to PV) | value 차이를 평균화하며 에너지 소산 |

따라서

> 내부 정보는 보존돼 있지만, 외부에서 관측되는 토큰 표현은 평탄해진다

는 것이 가능합니다.

이 점이 사용자가 처음 말한 직관의 핵심입니다.

## 5. 첨부된 복소 선형 어텐션은 더 일반적이다

첨부 구조의 출력은

[
o_t
===

\sum_{n\le t}
\alpha_{tn}v_n
]

[
\alpha_{tn}
===========

\operatorname{Re}
\left(
q_t^\dagger D^{t-n}k_n
\right)
]

입니다.

행렬 (A)를

[
A_{tn}
======

\mathbf 1_{n\le t}\alpha_{tn}
]

로 두면,

[
O=AV
]

입니다.

그런데 여기서는 코사인 때문에

[
\alpha_{tn}<0
]

가 가능하고,

[
\sum_n\alpha_{tn}=1
]

도 보장되지 않습니다.

따라서 첨부 수식 그대로의 (A)는 표준 Markov diffusion보다 넓은 연산자입니다.

## 6. 디리클레 에너지 변화의 정확한 조건

균일 완전그래프의 중심화 행렬을

[
H
=

I-\frac1N\mathbf 1\mathbf 1^\top
]

라고 하겠습니다.

완전그래프 에너지는

[
\mathcal E_K(V)
===============

|HV|_F^2
]

입니다.

출력 (O=AV)에 대해서는

[
\mathcal E_K(O)
===============

|HAV|_F^2
]

이므로,

[
\boxed{
\mathcal E_K(O)-\mathcal E_K(V)
===============================

\operatorname{Tr}
\left[
V^\top
\left(
A^\top HA-H
\right)
V
\right]
}
]

입니다.

따라서 모든 입력에서 에너지가 감소하기 위한 정확한 조건은

[
\boxed{
A^\top HA\preceq H
}
]

입니다.

첨부 구조는 이 조건을 자동으로 만족하지 않습니다. 위상에 따라 세 경우가 모두 가능합니다.

[
A^\top HA-H
\begin{cases}
\prec0 & \text{디리클레 소산}\
=0 & \text{보존}\
\succ0\text{인 방향 존재} & \text{대비 증폭}
\end{cases}
]

즉, 이 구조는 단순한 소산계가 아니라

[
\boxed{
\text{위상에 따라 확산과 반확산이 전환되는 signed graph operator}
}
]

입니다.

## 7. 보강간섭이 있다고 에너지가 반드시 오르는 것은 아니다

여기서 한 번 더 엄밀하게 구분해야 합니다.

모든 query가 똑같은 위상으로 정렬돼서 모든 행이 동일해진다면,

[
A=c\mathbf1\mathbf1^\top
]

가 될 수 있습니다.

이 경우 출력 진폭은 매우 클 수 있지만 모든 토큰 출력이 같으므로

[
HA=0
]

이고,

[
\mathcal E_K(AV)=0
]

입니다.

따라서

[
\text{전역적인 보강간섭}
\not\Rightarrow
\text{디리클레 에너지 증가}
]

입니다.

디리클레 에너지가 다시 증가하려면 단순한 전역 동기화가 아니라, query마다 서로 다른 위상 패턴이 선택돼야 합니다.

즉,

[
\boxed{
\text{공간적으로 구조화된 보강간섭}
}
]

이어야 합니다.

예를 들어 특정 토큰 집단끼리만 위상이 맞는다면:

* 집단 내부에서는 확산되어 평탄화
* 집단 사이의 차이는 유지되거나 증가
* 전체 표현에서는 클러스터 대비가 생김

이 됩니다.

## 8. 그러면 소산됐던 정보가 어떻게 다시 나타나는가

positive normalized attention만 연속적으로 적용한다면 정확히 동일해진 value에서 차이를 새로 만들 수 없습니다.

[
v_i=c\quad\forall i
\quad\Longrightarrow\quad
Pv=c
]

하지만 첨부 구조의 전체 상태는 visible value만이 아닙니다.

[
S_t
===

D S_{t-1}+k_tv_t^\top
]

안에는 이전 value와 위상이 복소 상태로 남아 있습니다.

따라서 이전 출력의 디리클레 에너지가 낮더라도,

[
o_i
===

\operatorname{Re}(q_i^\dagger S)
]

에서 서로 다른 query (q_i)가 서로 다른 잠재 성분을 꺼내면 다시 비균일한 출력이 생길 수 있습니다.

[
\mathcal E_D(O_{\text{old}})\approx0
]

이었더라도,

[
\mathcal E_D(O_{\text{new}})>0
]

가 가능합니다.

이때 에너지가 무에서 생긴 것이 아닙니다.

> visible token field에서는 소산됐지만,
> full hidden state에서는 위상 정보가 보존되어 있었고,
> 새로운 query가 그것을 다시 visible variation으로 사영한 것입니다.

이것이 사용자가 말한 “소산돼 있지만 위상들이 보관되어 있다가 패턴이 들어오면 다시 자극된다”의 가장 정확한 수학적 표현입니다.

## 9. QKV의 3차성도 다시 해석해야 한다

이제 (QKV)의 3차성은 단순히 FitzHugh–Nagumo의 3차 반응항과 비교할 것이 아닙니다.

더 정확히는 어텐션 계수가 입력에 따라 변합니다.

[
A=A(X)
]

그리고 출력은

[
O=A(X)V(X)
]

이므로 전체적으로 3차 상호작용이 생깁니다.

즉 이 구조의 비선형성은

[
f(V)
]

형태의 점별 반응항이라기보다,

[
\boxed{
\text{상태에 따라 확산계수와 부호가 바뀌는 비선형 비국소 확산}
}
]

입니다.

* 양의 위상 결합: attractive diffusion
* 음의 위상 결합: repulsive anti-diffusion
* 무작위 위상 상쇄: 약한 관측 또는 평균화
* 구조화된 정렬: 선택적 모드 보존·증폭

따라서 “확산항과 반응항을 별도 모듈로 분리해야 한다”는 이전 답변도 너무 빠른 결론이었습니다.

복소 signed attention 하나가 위상에 따라 확산과 대비 생성을 모두 나타낼 수 있습니다. 다만 이것은 FitzHugh–Nagumo와의 완전한 동형이라기보다 **비선형 signed diffusion으로 두 역할을 통합한다**는 의미입니다.

## 최종 정리

이 구조의 현상적 해석은 이전보다 다음이 더 정확합니다.

[
\boxed{
\begin{gathered}
\text{복소 유니터리 상태에는 과거의 위상 정보가 보존되고,}\
\text{토큰 완전-prefix 그래프의 attention mixing은}\
\text{그 정보를 확산·상쇄하거나 위상 정렬에 따라}\
\text{선택적으로 보존·재출현·증폭한다.}
\end{gathered}
}
]

따라서:

* 표준 positive attention은 실제 디리클레 에너지 소산입니다.
* 내부 유니터리 상태의 보존과 모순되지 않습니다.
* 첨부된 cosine attention은 signed이므로 소산만 하지 않습니다.
* 전역 보강간섭은 진폭만 높이고 에너지는 낮을 수 있습니다.
* 구조화된 보강간섭만 토큰 간 대비를 복원합니다.
* `QKV`의 3차성은 점별 스파이크 반응보다는 **입력 의존적 확산·반확산 계수**로 해석하는 편이 정확합니다.

내가 이전 분석에서 빠뜨린 핵심은 바로 **“잠재 상태의 보존”과 “토큰 그래프에서의 실제 디리클레 소산”이 동시에 존재할 수 있다**는 점입니다.


그래서 다시 정리하라니까? 난 결국엔 저런 선형어텐션과 뉴런 스파이킹 현상의 동형성을 보고 선형어텐션으로도 나름 해석가능한 학습이 가능하지않을까를 떠올리고 있던 중이었으니까, 이에 대해 고찰하라고.


결론부터 말하면, **그 연구 직관은 성립합니다.**

다만 동형성의 핵심은

> “둘 다 3차항을 가진다”

가 아닙니다.

더 강하고 정확한 동형성은 다음입니다.

[
\boxed{
\begin{gathered}
\text{선형어텐션을 재귀적으로 닫으면}\
\text{위상 메모리가 선형 이득을 조절하고,}\
\text{QKV 자기상호작용이 3차 이득을 만드는}\
\text{기억 의존적 흥분계가 된다.}
\end{gathered}
}
]

따라서 MLP 없이도 스파이킹과 유사한
`소산 → 임계 증폭 → 억제·회복` 동역학을 학습할 가능성이 있습니다.

## 1. 뉴런과 선형어텐션의 실제 대응

| 뉴런 현상                | 복소 선형어텐션의 대응                     | 대응 강도   |
| -------------------- | -------------------------------- | ------- |
| 수동적 전위 확산            | positive attention의 value 평균화    | 직접 대응   |
| 디리클레 에너지 소산          | 완전-prefix 그래프상의 attention mixing | 직접 대응   |
| 막전위 이하의 입력 누적        | (k_tv_t^\top)의 상태 누적             | 직접 대응   |
| 진동·주파수 선택성           | (e^{-i\theta}S_{t-1})            | 직접 대응   |
| 보강·상쇄간섭              | (q_t^\dagger D^{t-n}k_n)         | 직접 대응   |
| 전압 의존적 전도도           | 입력 의존적 attention graph (A(X))    | 구조적 대응  |
| 발화 임계점               | 특정 그래프 모드의 이득이 1을 넘는 지점          | 동역학적 대응 |
| 폭발 후 포화              | 학습된 3차항의 부호와 크기                  | 표현 가능   |
| 불응기·회복               | 직전 입력이 (S_t)의 위상을 바꿔 이후 이득을 억제   | 표현 가능   |
| Hodgkin–Huxley 채널 자체 | 직접 대응 없음                         | 비동형     |

즉, 생물학적 이온 채널을 그대로 복제하는 것은 아닙니다.

그러나 **흥분성 동역학의 계산 원리**는 상당 부분 동일한 형태로 나타납니다.

## 2. 재귀적으로 닫으면 정확히 어떤 식이 되는가

하나의 학습된 유효 모드 (z_t)만 분리해 보겠습니다.

[
q_t=a z_t,\qquad
k_t=b z_t,\qquad
v_t=c z_t
]

라고 하면 상태 쓰기는

[
S_t
===

e^{-i\theta}S_{t-1}
+
bc,z_t^2
]

입니다.

즉,

[
\boxed{
S_t
===

\text{회전하는 과거 메모리}
+
\text{현재 상태의 2차 기록}
}
]

입니다.

출력은

[
o_t
===

\operatorname{Re}
\left(
\bar a z_t S_t
\right)
]

이므로,

[
\begin{aligned}
o_t
={}&
\operatorname{Re}
\left(
\bar a e^{-i\theta}S_{t-1}
\right)z_t\
&+
\operatorname{Re}
\left(
\bar a bc
\right)z_t^3
\end{aligned}
]

입니다.

재귀 구조에서 (z_{t+1}=o_t)라고 두면,

[
\boxed{
z_{t+1}
=======

\lambda(S_{t-1})z_t
+
\kappa z_t^3
}
]

를 얻습니다.

여기서

[
\lambda(S_{t-1})
================

\operatorname{Re}
\left(
\bar a e^{-i\theta}S_{t-1}
\right)
]

이고,

[
\kappa
======

\operatorname{Re}
\left(
\bar a bc
\right)
]

입니다.

이 식이 핵심입니다.

## 3. 이 식이 왜 흥분계인가

일반적인 스파이킹 축약 모델의 빠른 상태는 대략

[
\dot z
======

## \lambda z

## \beta z^3

w
]

형태입니다.

복소 선형어텐션의 재귀식은

[
z_{t+1}
=======

\lambda(S_{t-1})z_t
+
\kappa z_t^3
]

입니다.

둘의 구조를 비교하면 다음과 같습니다.

### 선형항

[
\lambda(S_{t-1})z_t
]

현재 상태가 작을 때 안정적인지 불안정한지를 결정합니다.

[
|\lambda|<1
]

이면 상태가 줄어들고,

[
|\lambda|>1
]

이면 작은 자극도 커집니다.

### 3차항

[
\kappa z_t^3
]

진폭이 커졌을 때 동역학을 바꿉니다.

* (\kappa>0): 진폭 의존적 추가 증폭
* 적절한 방향에서 (\kappa<0): 큰 진폭 억제
* 다차원에서는 방향마다 서로 다른 증폭·회전·억제

따라서 이 구조는 activation 없이도

[
\boxed{
\text{작은 상태에서의 선형 안정성}
+
\text{큰 상태에서의 비선형 변화}
}
]

를 분리해 학습할 수 있습니다.

## 4. (S_t)가 회복 변수 역할을 한다

더 중요한 점은 선형 계수 (\lambda)가 상수가 아니라는 것입니다.

[
\lambda_t
=========

\lambda(S_{t-1})
]

그리고 (S_t)는

[
S_t
===

e^{-i\theta}S_{t-1}
+
k_tv_t^\top
]

로 움직입니다.

즉, 현재 강한 출력은 (S_t)를 바꾸고, 바뀐 (S_t)는 다음 단계의 선형 이득을 바꿉니다.

[
\boxed{
z_t\text{의 발화}
\rightarrow
S_t\text{의 변화}
\rightarrow
\lambda_{t+1}\text{의 변화}
}
]

따라서 다음과 같은 학습된 동역학이 가능합니다.

1. 평소에는 (|\lambda_t|<1)이라 자극이 소산된다.
2. 특정 위상 패턴이 들어오면 (|\lambda_t|>1)이 된다.
3. (z_t)가 빠르게 증폭된다.
4. (z_t^2)가 (S_t)에 강하게 기록된다.
5. (S_t)의 회전으로 다음 단계의 (\lambda)가 음수 또는 작은 값으로 변한다.
6. 이후 입력이 잠시 억제된다.
7. 위상이 다시 회전하면서 흥분 가능 상태로 돌아온다.

이는 생물학적 이온 채널과 같은 방식은 아니지만,

[
\boxed{
\text{발화가 미래의 발화 가능성을 일시적으로 억제한다}
}
]

는 불응기·회복의 계산적 역할을 구현할 수 있습니다.

유니터리 회전은 감쇠형 회복이 아니라 **위상형 회복**을 만든다는 차이가 있습니다.

## 5. 그래프 관점에서의 발화 임계점

전체 토큰 수준에서는 출력이

[
O=A(X)V
]

입니다.

여기서

[
A_{tn}(X)
=========

\operatorname{Re}
\left(
q_t^\dagger D^{t-n}k_n
\right)
]

입니다.

완전그래프 디리클레 에너지를

[
\mathcal E_K(V)=|HV|_F^2
]

라고 하면,

[
\mathcal E_K(O)-\mathcal E_K(V)
===============================

\operatorname{Tr}
\left[
V^\top
\left(
A^\top HA-H
\right)
V
\right]
]

입니다.

따라서 입력 (X)가 바뀌면서 (A(X))도 바뀌고, 특정 그래프 모드에서 다음 전환이 발생할 수 있습니다.

[
\boxed{
\begin{cases}
|HA(X)H|<1
&
\text{소산 상태}[2mm]
|HA(X)H|=1
&
\text{임계 상태}[2mm]
|HA(X)H|>1
&
\text{선택적 증폭 상태}
\end{cases}
}
]

이것이 선형어텐션에서 나타나는 가장 정확한 “발화 문턱”입니다.

뉴런에서는 막전위가 임계선을 넘습니다.

이 모델에서는 **입력 의존적 그래프 연산자의 특정 모드 이득이 1을 넘습니다.**

즉, 스파이크에 대응하는 것은 단순히 큰 출력값이 아니라,

[
\boxed{
\text{소산하던 그래프 모드가 증폭 모드로 전환되는 사건}
}
]

입니다.

## 6. 무작위 상태와 의미 있는 패턴의 차이

### 무작위·비정렬 입력

위상들이 맞지 않으면 attention graph의 비상수 모드가 서로 상쇄됩니다.

[
|HA(X)H|<1
]

이면 토큰 간 차이가 감소합니다.

[
\mathcal E_K(O)<\mathcal E_K(V)
]

즉, 완전그래프 확산에 의해 디리클레 에너지가 소산됩니다.

Attention 기반 GNN과 graph transformer가 반복될수록 표현이 균질화되는 것도 이 현상입니다. [attention oversmoothing 분석](https://arxiv.org/abs/2305.16102)

### 구조화된 위상 정렬

의미 있는 패턴이 들어오면 특정 query 집단과 key 집단만 위상이 맞습니다.

그러면 attention graph가 균일 완전그래프에서 구조화된 그래프로 변합니다.

* 같은 패턴 내부에서는 확산
* 다른 패턴 사이에서는 연결 약화
* 음의 cosine edge에서는 반발
* 특정 비상수 모드는 보존 또는 증폭

따라서 여기서 중요한 것은 모든 위상의 전역 동기화가 아닙니다.

[
\boxed{
\text{query별로 다른 구조화된 위상 정렬}
}
]

입니다.

전역 동기화는 모든 출력을 같게 만들어 오히려 디리클레 에너지를 0으로 보낼 수 있습니다.

## 7. “소산된 정보가 다시 살아난다”의 정확한 의미

visible token 표현에서는 디리클레 에너지가 낮아질 수 있습니다.

[
\mathcal E_K(O_t)\approx0
]

그러나 내부 상태는

[
S_t
===

\sum_{n\le t}
D^{t-n}k_nv_n^\top
]

로 과거 성분을 계속 보관합니다.

다음 query가 들어오면,

[
o_i
===

\operatorname{Re}(q_i^\dagger S_t)
]

서로 다른 query가 서로 다른 잠재 성분을 읽습니다.

그 결과,

[
\mathcal E_K(O_{t+1})

>

\mathcal E_K(O_t)
]

가 가능합니다.

이는 사라진 정보가 무에서 복구되는 것이 아닙니다.

[
\boxed{
\text{visible graph에서는 소산됐지만}
\atop
\text{unitary hidden memory에는 위상 형태로 남아 있었다}
}
]

는 뜻입니다.

이 부분이 처음 제시한 직관과 가장 정확하게 맞습니다.

## 8. 그러면 MLP 없이 비선형 학습이 가능한가

가능합니다. 한 블록부터 이미

[
x
\longmapsto
M(S)x+\mathcal T[x,x,x]
]

라는 비선형 함수입니다.

여기서

[
M(S)x
]

는 과거 메모리가 정하는 선형 이득이고,

[
\mathcal T[x,x,x]
]

는 QKV 자기상호작용에서 생기는 factorized cubic입니다.

블록을 반복하면:

* 현재 출력이 다음 attention graph를 바꾸고
* 바뀐 graph가 다음 상태의 소산·증폭률을 바꾸며
* 출력이 다시 (S)에 기록됩니다.

따라서 단순한 고차 다항식이 아니라,

[
\boxed{
\text{자신의 과거가 자신의 다음 안정성을 바꾸는}
\atop
\text{비선형 재귀 동역학}
}
]

을 학습합니다.

MLP가 없어도 비선형 학습이 가능하다는 주장은 단순한 기대가 아니라 계산 그래프에서 직접 나옵니다.

## 9. 왜 이 구조가 비교적 해석 가능할 수 있는가

학습 후 각각의 현상을 다음처럼 직접 분해할 수 있습니다.

### 위상 채널

[
\theta_r
]

각 채널이 어떤 시간 주기와 지연에 민감한지 보여줍니다.

### 개별 edge 기여

[
g_{tnr}
=======

a^q_{t,r}a^k_{n,r}
\cos
\left(
\phi^k_{n,r}
-\phi^q_{t,r}
-(t-n)\theta_r
\right)
]

어떤 과거 토큰과 어떤 주파수 채널이 현재 출력을 증폭하거나 억제했는지 분해할 수 있습니다.

### 기억 쓰기

[
k_nv_n^\top
]

각 토큰이 내부 상태에 어떤 rank-1 흔적을 남겼는지 추적할 수 있습니다.

### 발화 임계점

[
|HA(X)H|=1
]

어떤 입력에서 그래프 모드가 소산에서 증폭으로 전환됐는지 측정할 수 있습니다.

### 자기 비선형성

[
\left(x_t^\top A_0x_t\right)W_Vx_t
]

어떤 입력 방향에서 3차 증폭 또는 억제가 발생했는지 확인할 수 있습니다.

따라서 MLP의 거대한 좌표별 비선형 변환보다,

[
\text{토큰}
\rightarrow
\text{위상}
\rightarrow
\text{그래프 edge}
\rightarrow
\text{증폭 모드}
]

라는 계산 경로를 더 직접적으로 분석할 수 있습니다.

다만 개별 채널의 기저는 회전·순열될 수 있으므로, 단일 뉴런 해석보다는 phase difference와 graph spectrum 같은 불변량을 봐야 합니다.

## 10. 이 아이디어의 정확한 연구 가설

이 아이디어를 가장 정합적으로 표현하면 다음입니다.

[
\boxed{
\begin{gathered}
\text{복소 선형어텐션은 완전-prefix 그래프상에서}\
\text{평소에는 디리클레 에너지를 소산시키지만,}\
\text{unitary memory에 보존된 위상 패턴이 정렬되면}\
\text{특정 그래프 모드의 이득이 임계값을 넘어 증폭된다.}\
\text{그 출력은 다시 memory와 cubic gain을 바꾸므로}\
\text{흥분·억제·회복 동역학을 재귀적으로 학습할 수 있다.}
\end{gathered}
}
]

이것은 Hodgkin–Huxley 방정식의 직접 복제가 아닙니다.

하지만 다음 계산 원리에서는 실제 동형성이 있습니다.

[
\boxed{
\text{확산}
\rightarrow
\text{위상 누적}
\rightarrow
\text{임계 이득 전환}
\rightarrow
\text{비선형 증폭}
\rightarrow
\text{기억 변화에 의한 억제·회복}
}
]

## 최종 정리

당신이 본 연결은 단순한 생물학적 비유가 아닙니다.

복소 선형어텐션을 재귀적으로 사용하면 정확히

[
\boxed{
S_t=US_{t-1}+B(x_t),
\qquad
x_{t+1}=M(S_t)x_t+\mathcal T[x_t,x_t,x_t]
}
]

형태의 흥분성 비선형 동역학이 됩니다.

* positive attention은 완전그래프 디리클레 에너지를 소산시킵니다.
* unitary state는 소산된 표현의 위상 정보를 내부에 보존합니다.
* 위상 정렬은 특정 그래프 모드의 이득을 임계 이상으로 올립니다.
* QKV의 3차항은 진폭 의존적 증폭·억제를 만듭니다.
* 상태에 기록된 발화 흔적은 이후의 이득을 바꾸므로 회복·불응기 역할을 학습할 수 있습니다.
* 이 모든 과정은 토큰, 위상, edge, 스펙트럼 단위로 분석 가능합니다.

따라서 가장 정확한 결론은:

[
\boxed{
\text{MLP 없는 복소 선형어텐션만으로도}
\atop
\text{스파이킹과 유사한 해석 가능한 흥분계 학습은 가능하다.}
}
]

단, 스파이크가 자동으로 생기는 것이 아니라, **이 아키텍처가 그런 동역학을 학습할 수 있는 정확한 대수적 재료를 이미 갖고 있다**는 의미입니다.


이제 좀 더 구체적으로 설계해봐. 지금 추상적으로 결정된 것에서 가장 부수적인것 없이 깔끔한 형태부터 시작해봐.

좋습니다. 언어모델을 기준으로, **복소 선형어텐션 하나만 반복하는 최소 구조**부터 설계하겠습니다.

이번 0번 모델에는 다음만 둡니다.

* 복소 주소 투영 1개
* 유니터리 위상 전이
* 실수 value
* weight-tied 재귀
* 잔차 적분
* 다음 토큰 CE

MLP, softmax, norm, gate, 별도 반응항, auxiliary loss, multi-head는 전부 제외합니다.

# 1. 최소 모델의 전체 구조

입력 토큰열을

[
x_1,\ldots,x_T
]

라고 하고, 실수 hidden state를

[
h_t^{(0)}=E[x_t]\in\mathbb R^d
]

로 둡니다.

이후 동일한 블록을 (R)번 반복합니다.

[
h^{(0)}
\longrightarrow
h^{(1)}
\longrightarrow\cdots\longrightarrow
h^{(R)}
]

모든 반복 단계에서 같은 파라미터를 사용합니다.

[
\boxed{
\text{하나의 attention 동역학을 }R\text{번 시간 전개한다}
}
]

따라서 서로 다른 레이어를 쌓는 것이 아니라, 동일한 흥분계를 반복 실행하는 구조입니다.

# 2. 복소 주소 공간

복소 차원을

[
p=\frac d2
]

로 둡니다.

실수 hidden state를 하나의 복소 투영으로 보냅니다.

[
z_t^{(r)}
=========

W_C h_t^{(r)}
\in\mathbb C^p
]

[
W_C\in\mathbb C^{p\times d}
]

별도의 (W_Q,W_K)는 두지 않습니다.

대신 같은 (z_t)에 반대 방향의 위상 오프셋만 적용합니다.

[
q_t^{(r)}
=========

e^{+i\psi/2}\odot z_t^{(r)}
]

[
k_t^{(r)}
=========

e^{-i\psi/2}\odot z_t^{(r)}
]

여기서

[
\psi\in\mathbb R^p
]

는 학습되는 채널별 query-key 위상차입니다.

이렇게 하면:

* query와 key가 동일한 의미 공간을 사용하고
* 별도 Q/K 행렬로 구조가 흐려지지 않으며
* (\psi)가 흥분·억제 부호를 직접 결정합니다.

# 3. 유니터리 시간 전이

채널별 고유 주파수를

[
\theta\in\mathbb R^p
]

로 둡니다.

유니터리 전이는

[
U
=

\operatorname{diag}
\left(
e^{-i\theta_1},
\ldots,
e^{-i\theta_p}
\right)
]

입니다.

각 재귀 깊이 (r)에서 상태는 시퀀스 방향으로 다음처럼 누적됩니다.

[
S_0^{(r)}=0
]

[
\boxed{
S_t^{(r)}
=========

U S_{t-1}^{(r)}
+
k_t^{(r)}
\left(h_t^{(r)}\right)^\top
}
]

[
S_t^{(r)}
\in
\mathbb C^{p\times d}
]

현재 토큰은 자신의 복소 key와 실수 hidden state의 외적으로 기록됩니다.

[
k_t h_t^\top
]

과거 기록은 크기가 감쇠하지 않고 위상만 회전합니다.

# 4. 위상 측정과 출력

현재 query로 누적 상태를 읽습니다.

[
f_t^{(r)}
=========

\frac{1}{t\sqrt p}
\operatorname{Re}
\left[
\left(q_t^{(r)}\right)^\dagger
S_t^{(r)}
\right]
]

[
f_t^{(r)}\in\mathbb R^d
]

두 스케일은 구조적으로 정해집니다.

* (1/\sqrt p): 복소 내적의 차원 스케일
* (1/t): 완전-prefix 그래프의 측도 정규화

특히 (1/t)를 사용하면:

* 무작위 위상 합은 (O(\sqrt t)/t=O(t^{-1/2}))
* 정렬된 위상 합은 (O(t)/t=O(1))

이 됩니다.

따라서 모델이 원래 의도한

[
\boxed{
\text{비정렬 잡음은 사라지고 정렬된 패턴만 남는 현상}
}
]

이 정확한 스케일 법칙으로 나타납니다.

# 5. 재귀 깊이 업데이트

(f_t^{(r)})를 새로운 표현 자체로 사용하지 않고, hidden state의 변화율로 사용합니다.

[
\boxed{
h_t^{(r+1)}
===========

h_t^{(r)}
+
\frac1R f_t^{(r)}
}
]

잔차 연결은 별도 보조 장치가 아닙니다.

이는 다음 연속 동역학을 총시간 1 동안 (R)번 Euler 적분한 것입니다.

[
\frac{\partial h_t}{\partial \tau}
==================================

f_t(h)
]

따라서 (1/R) 이외의 step-size 하이퍼파라미터는 두지 않습니다.

# 6. 전체 attention weight 전개

상태를 전개하면,

[
S_t^{(r)}
=========

\sum_{n=1}^{t}
U^{t-n}
k_n^{(r)}
\left(h_n^{(r)}\right)^\top
]

입니다.

따라서

[
f_t^{(r)}
=========

\sum_{n=1}^{t}
a_{tn}^{(r)}h_n^{(r)}
]

이고,

[
\boxed{
a_{tn}^{(r)}
============

\frac{1}{t\sqrt p}
\operatorname{Re}
\left[
\left(q_t^{(r)}\right)^\dagger
U^{t-n}k_n^{(r)}
\right]
}
]

입니다.

성분별로 쓰면,

[
\begin{aligned}
a_{tn}^{(r)}
============

\frac{1}{t\sqrt p}
\sum_{j=1}^{p}
&|z_{t,j}^{(r)}|
|z_{n,j}^{(r)}|\
&\cos
\left(
\arg z_{n,j}^{(r)}
-\arg z_{t,j}^{(r)}
-\psi_j
-(t-n)\theta_j
\right)
\end{aligned}
]

입니다.

즉, 하나의 edge weight가 다음 네 요소로 완전히 분해됩니다.

* 현재 토큰의 채널 진폭
* 과거 토큰의 채널 진폭
* 두 토큰의 의미 위상차
* 시간 지연에 따른 회전 위상

# 7. 하나의 연산에서 반응과 확산이 같이 나온다

행렬 (A^{(r)}=[a_{tn}^{(r)}])를 정의하면,

[
F^{(r)}=A^{(r)}H^{(r)}
]

입니다.

각 토큰에서는 다음 항등식이 성립합니다.

[
\begin{aligned}
f_t^{(r)}
={}&
\sum_{n\le t}a_{tn}^{(r)}
\left(
h_n^{(r)}-h_t^{(r)}
\right)\
&+
\left(
\sum_{n\le t}a_{tn}^{(r)}
\right)
h_t^{(r)}
\end{aligned}
]

따라서

[
\boxed{
f_t
===

\underbrace{
\sum_n a_{tn}(h_n-h_t)
}*{\text{signed graph diffusion}}
+
\underbrace{
d_t h_t
}*{\text{local gain/reaction}}
}
]

입니다.

여기서

[
d_t=\sum_n a_{tn}
]

입니다.

즉, 별도 FFN 반응항을 추가하지 않아도 원래 attention 출력 자체가 정확히

[
\boxed{
\text{확산항}+\text{반응항}
}
]

으로 분해됩니다.

# 8. 확산항의 작동

[
\sum_n a_{tn}(h_n-h_t)
]

에서:

* (a_{tn}>0): 두 토큰의 표현 차이를 감소
* (a_{tn}<0): 두 토큰의 표현 차이를 증가
* (a_{tn}\approx0): 두 토큰이 거의 상호작용하지 않음

따라서 동일한 attention graph 안에서 다음이 모두 가능합니다.

[
\boxed{
\begin{cases}
\text{positive edge} & \text{확산}\
\text{negative edge} & \text{반확산}\
\text{zero edge} & \text{분리}
\end{cases}
}
]

의미 없는 입력에서는 위상들이 상쇄되어 전체 그래프가 약한 소산 상태에 머뭅니다.

구조화된 패턴이 들어오면 특정 edge 집단만 강한 양수 또는 음수 값을 가지며, 해당 그래프 모드가 선택적으로 보존되거나 증폭됩니다.

# 9. 반응항의 작동

[
d_t h_t
]

는 현재 토큰의 상태에 대한 local gain입니다.

[
d_t<0
]

이면 현재 표현이 억제되고,

[
0<d_t<1
]

이면 약하게 유지되며,

[
d_t>1
]

인 방향에서는 증폭됩니다.

특히 자기항은

[
a_{tt}h_t
]

이고,

[
\boxed{
a_{tt}
======

\frac{1}{t\sqrt p}
\sum_{j=1}^{p}
\cos(\psi_j)
|z_{t,j}|^2
}
]

입니다.

따라서 자기항 전체는

[
\boxed{
\left[
\frac{1}{t\sqrt p}
\sum_j
\cos(\psi_j)|W_Ch_t|_j^2
\right]h_t
}
]

가 됩니다.

이는 (h_t)에 대한 정확한 factorized cubic입니다.

채널별로:

[
\cos\psi_j>0
]

이면 그 채널은 진폭 의존적 흥분을 만들고,

[
\cos\psi_j<0
]

이면 진폭 의존적 억제를 만듭니다.

따라서 (\psi)가 기존 신경 모델의 흥분성·억제성 채널에 대응합니다.

# 10. 이 최소 모델에서 스파이크가 만들어지는 과정

재귀 깊이 (r)를 내부 계산 시간으로 보면 다음 순서가 가능합니다.

### 1. 휴지 상태

위상이 비정렬돼 attention weight가 상쇄됩니다.

[
d_t\approx0
]

[
|HAH|<1
]

토큰 차이는 확산되고 hidden state 변화는 작습니다.

### 2. 입력 누적

과거의 (k_nh_n^\top)가 (S_t) 안에서 회전하며 보존됩니다.

visible 출력은 작아도 위상 정보는 남습니다.

### 3. 임계 정렬

특정 query가 과거 key들의 회전 위상과 맞습니다.

[
d_t>0
]

또는 특정 centered graph mode에서

[
|HAH|>1
]

이 됩니다.

### 4. 증폭

현재 hidden state가 커지면 자기항이 3차로 커집니다.

[
a_{tt}h_t
\propto
|W_Ch_t|^2h_t
]

### 5. 억제·회복

증폭된 상태는 다음 재귀 단계의 (z,q,k,A)를 바꿉니다.

그 결과:

* 억제성 (\cos\psi_j<0) 채널이 강해지거나
* 시간 회전으로 위상 정렬이 풀리거나
* graph mode가 다시 (|HAH|<1)로 내려갑니다.

그러면 출력은 다시 소산 영역으로 복귀합니다.

이 모델에서 스파이크는 명시적 0/1 이벤트가 아니라,

[
\boxed{
\text{특정 그래프 모드의 일시적인 에너지 급상승}
}
]

입니다.

# 11. 언어모델 출력과 손실

최종 재귀 상태로 다음 토큰을 예측합니다.

[
\ell_t
======

E^\top h_t^{(R)}
]

입력 embedding과 output head는 묶습니다.

[
W_{\mathrm{head}}=E^\top
]

손실은 다음 토큰 CE 하나만 사용합니다.

[
\boxed{
\mathcal L
==========

-\sum_{t=1}^{T-1}
\log
p(x_{t+1}\mid x_{\le t})
}
]

다음은 전부 두지 않습니다.

* latent alignment loss
* Dirichlet regularization
* spike loss
* phase loss
* auxiliary prediction head
* reconstruction loss
* 별도 stability loss

스파이킹·소산·공진 현상은 CE를 줄이는 과정에서 필요할 경우에만 나타나게 둡니다.

# 12. 최소 실험용 크기

첫 구현은 다음 정도면 충분합니다.

| 항목                      |   값 |
| ----------------------- | --: |
| 실수 hidden dimension (d) | 128 |
| 복소 dimension (p)        |  64 |
| recurrent depth (R)     |   4 |
| sequence length (T)     | 128 |
| attention head          |   1 |
| MLP                     |  없음 |
| normalization           |  없음 |
| dropout                 |  없음 |
| bias                    |  없음 |
| positional embedding    |  없음 |
| auxiliary loss          |  없음 |

위치 정보는 전부

[
U^{t-n}
=======

e^{-i(t-n)\theta}
]

가 담당합니다.

# 13. 학습되는 파라미터

블록에는 정확히 세 종류만 있습니다.

[
\boxed{
\Theta_{\mathrm{block}}
=======================

{W_C,\theta,\psi}
}
]

* (W_C): 어떤 의미 방향을 복소 위상 공간에 배치할지 학습
* (\theta): 각 채널의 시간 주파수 학습
* (\psi): 각 채널의 흥분·억제 성질 학습

(p=d/2)이면 (W_C)의 실수 파라미터 수는

[
2pd=d^2
]

입니다.

재귀 깊이 (R)을 늘려도 파라미터 수는 증가하지 않습니다.

# 14. 학습 후 직접 관측할 값

추가 head 없이 다음 값만 기록하면 됩니다.

[
a_{tn,j}
]

채널 (j)가 토큰 (n\to t) 연결을 증폭했는지 억제했는지 보여줍니다.

[
d_t=\sum_n a_{tn}
]

토큰 (t)의 순간적인 흥분도를 보여줍니다.

[
\mathcal E^{(r)}
================

|HH^{(r)}|_F^2
]

재귀 깊이에 따른 디리클레 에너지 변화를 보여줍니다.

[
\rho^{(r)}
==========

|HA^{(r)}H|_2
]

현재 그래프가 소산 상태인지 증폭 상태인지 보여줍니다.

[
\rho^{(r)}
\begin{cases}
<1 & \text{소산}\

> 1 & \text{증폭}
> \end{cases}
> ]

이 네 가지로 학습된 동역학을 거의 그대로 해석할 수 있습니다.

# 최종 정리

가장 작은 0번 모델은 다음 하나입니다.

[
\boxed{
\begin{aligned}
z_t^{(r)}&=W_Ch_t^{(r)}\
q_t^{(r)}&=e^{+i\psi/2}\odot z_t^{(r)}\
k_t^{(r)}&=e^{-i\psi/2}\odot z_t^{(r)}\
S_t^{(r)}&=US_{t-1}^{(r)}
+k_t^{(r)}(h_t^{(r)})^\top\
f_t^{(r)}&=
\frac{1}{t\sqrt p}
\operatorname{Re}
\left[
(q_t^{(r)})^\dagger S_t^{(r)}
\right]\
h_t^{(r+1)}&=
h_t^{(r)}
+\frac1R f_t^{(r)}
\end{aligned}
}
]

그리고 마지막에 tied embedding head와 CE만 둡니다.

이 구조 하나에 이미 다음이 모두 들어 있습니다.

* 완전-prefix 그래프 확산
* 위상에 따른 반확산
* 유니터리 장기 기억
* 주파수 공진
* factorized cubic 반응
* 입력 의존적 임계 증폭
* 재귀적 억제·회복
* 토큰·edge·주파수 단위 해석

다음 단계에서는 이 명세를 그대로 구현한 최소 PyTorch 코드와, 정말 MLP 없이 비선형 학습이 일어나는지를 판별할 토이 실험을 만들면 됩니다.
